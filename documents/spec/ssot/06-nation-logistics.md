## 6. 国家運営・物流・輸送

### 6.1 基本方針

Civ6の都市単位最適化だけではなく、国家が余剰資源・人員・物資を再分配し、飢餓・災害・侵略・都市壊滅へ対応する国らしい運営を実装する。

ただし、都市ごとに逐一手作業で輸送を命じることを必須にせず、手動操作とSecretaryへの委任を併用する。

### 6.2 国家備蓄

| 備蓄 | 主な供給源 | 主な用途 |
|---|---|---|
| 食料 | 食料余剰都市、農業、港、交易 | 飢餓地域、避難民、包囲都市、災害復興 |
| 人員 | 人口余剰、教育・訓練、雇用 | 災害派遣、復興、開拓、医療、軍事補充 |
| 医療 | 医療ジョブ、施設、交易 | 負傷、疫病、壊滅都市、遠征救援 |
| 金・交易力 | 商業、港、市場、交易路、税 | 緊急調達、補助金、外交、傭兵 |
| 建設資材 | 鉱山、工業、森林、輸送網 | 復興、城壁、施設修理、宇宙拠点 |
| エネルギー | 後期・宇宙施設、資源 | 通信、防衛、AI、宇宙兵站 |
| 研究資料 | 大学、研究都市、Artifact、遠征 | 技術、暗号解読、AI、宇宙計画 |

### 6.3 国家プロジェクト

| プロジェクト | 消費 | 効果 |
|---|---|---|
| 飢餓救援 | 食料、人員、交易力 | 飢餓・人口減少を抑制 |
| 災害復興 | 建設資材、人員、金 | 壊滅都市・破損施設・交通網を復旧 |
| 医療支援 | 医療、人員、金 | 負傷・疫病・神罰・襲来被害からの回復を加速 |
| 避難・再定住 | 食料、人員、金、住宅 | 危険地域の人口を安全地域へ移動 |
| 国家備蓄 | 食料、金、資材 | 災害・包囲・襲来に備える |
| 交通・通信整備 | 資材、研究、エネルギー | 輸送・連絡・救援速度を上げる |
| 緊急動員 | 人員、金、装備 | 防衛・復興・宇宙防衛の即応部隊を形成 |

### 6.4 輸送Unitと道路

物流はTrader Unitを拡張するイメージを基本とする。

| 輸送手段 | 前提 | 特徴 |
|---|---|---|
| 徒歩・荷駄 | 初期 | 遅い、短距離、軽量輸送 |
| Trader・荷車 | 交易路、道路、馬など | 都市間輸送の基本 |
| 船舶 | 港、航路、沿岸都市 | 大量物資、人員、重資材 |
| トラック・バイク | 道路網 + 近代文化・技術 | 高速。道路必須 |
| 鉄道 | 鉄道路線 + 技術 | 高容量。路線維持が必要 |
| ドローン | 通信・航空・AI・文化 | 道路不要、軽量物資、偵察、医療、通信 |
| 飛行機 | 飛行場・航空技術・燃料 | 道路不要、高速、運用コスト大 |
| ヘリコプター | 航空・軍事・救難 | 山岳・災害地・孤立地域救援 |
| 宇宙輸送 | 宇宙港、航路、推進剤、通信 | 惑星間物資・人員・Artifact |
| 次元輸送 | 異宇宙技術、暗号解読、条約 | 高価値品・特殊人材。高リスク |

#### 道路

- 道路は装飾ではなく、物流・救援・統治のインフラ
- トラック・バイク等は、都市間道路がないと走行できない
- 道路の建築、修理、延伸、橋、トンネル、港、空港をUnit・都市建設・国家プロジェクトで実行する
- 戦争、災害、神、異宇宙襲来で道路・港・鉄道・通信が破壊・封鎖され得る
- オフロードバイク、ドローン、飛行機、ヘリ等は文化・技術により道路依存を弱める

### 6.5 マップ移行時の資源

日本→世界→太陽系→銀河等は、より大きい新規マップを新規シナリオとして開始する。

| 項目 | 次マップへの扱い |
|---|---|
| 地形・領土タイル・物理資源 | 新規マップで再配置 |
| 都市・城・惑星・拠点 | 新規シナリオの初期状態として再配置・抽象化 |
| 道路・航路・物流網 | 新規マップの地理・時代・スケールに合わせて再構築 |
| 国家資源 | 初期備蓄、技術段階、制度、開始ボーナス、難易度補正へ変換 |
| 人物・Hero・Great Person | 継承枠、人物プール、開始候補として持込 |
| 装備・Artifact | 持込枠、Vault、展示、同調、解放フラグとして持込 |
| ジョブ・技術・制度 | 解放済み選択肢、初期ツリー、研究加速として持込 |
| 宗教・法律・家名・記憶 | 抽象継承。詳細は同一セーブ内で維持 |
