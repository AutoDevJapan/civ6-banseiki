## 9. 勢力吸収と宗教

### 9.1 勢力吸収

相手勢力を取り込む場合、都市・領土だけでなく人物・所持品・歴史資産を可能な限り引き継ぐ。

Hero は公式の「英雄と伝説（Heroes & Legends）」モードの仕組みを使う英傑武将を指す。このモードは必須とする。公式ゲームの既存の英雄は登場させず、万世紀の人物を独自に定義する。

吸収では英雄の本体と寿命、所有者、再召喚の権利を可能な限り引き継ぐ。契約・忠誠・関係値は万世紀の人物記録で管理する。
自害も吸収時の選択肢とする。再召喚権を引き継げない場合や英雄の移管処理でエラーが起きた場合は、自害として扱い、人物の記録と理由を残す。
この場合は継承に成功したとは記録しない。英雄以外の資産の移管エラーまで自害に置き換えない。

| 資産 | 吸収時の扱い |
|---|---|
| 都市・城・領土 | 移管。統治・忠誠・文化摩擦等を伴う |
| 一般Unit | 降伏、編入、解散、逃亡、抵抗から判定 |
| 武将 | 捕縛、登用、臣従、亡命、処刑、隠遁、離反等へ分岐 |
| Hero | 原則として即時消滅させず、契約・忠誠・寿命・関係値で登用、保護、再契約、離反、潜伏、自害を判定。再召喚権の継承ができない場合や英雄の移管エラーは、自害として理由を残す |
| Great Person相当 | 登用、亡命、隠遁等へ分岐。吸収側に残る偉人と人物化した総督は、本人の能力を保って人物のまま登用する。科学・信仰・文化への資産化は行わない |
| 装備・Artifact・収蔵品 | Vault、都市、城、人物に紐づけて移管・略奪・接収・返還・散逸を判定 |
| 解放ジョブ・技術・制度 | 人物・文書・施設・文化として一部継承・解放 |
| 宗教 | 信徒、聖地、聖職者、教典、遺物、宗派として残る |

吸収は軍事征服、小国懐柔、大国の合併などで起きる。相互保護・従属国・植民地国・連邦関係は両者が存続する関係宣言であり、それだけでは吸収にならない。旧9状態の「自治」「直轄」等を吸収方式として確定しない。詳細は9.4に従う。

#### 吸収の判定順序（Q84〜Q86 の確定回答）

Q84 のオーナー回答を原文のまま記録する。

> 誰をどうするか決める前に、ゲーム側で判定が入り、逃亡、隠遁、離反、潜伏、散逸が実行されるか決める(これらになった場合、対象者を蛮族もしくは蛮族などからの報酬として登場させる)。その後、残存したものを吸収する側が取捨選択する。その後、結果画面にて、選択した行為が成功したかどうかの判定を行う。成功したら、選択した通りになり、失敗したら、再度、逃亡、隠遁、離反、潜伏、散逸が実行されるか決める(これらになった場合、対象者を蛮族もしくは蛮族などからの報酬として登場させる)。

したがって、各人物・所持品・Artifactについて、吸収側の選択より先に一次の離脱判定を保存する。残ったものだけを選択し、選択した行為ごとに成否を判定する。失敗時にはその対象だけ一次と同じ離脱判定をもう一度行い、二度目に離脱しない対象は人物のまま捕縛・登用等の非産出の扱いに確定する。同じ段階の判定を読込や操作の再送で繰り返さない。離脱した対象は同一の人物・品物の記録を保持し、蛮族または野営地・集落の報酬を通じて後から再登場させる。

Q85 は **c（吸収方式ごとに忠誠と文化摩擦を変える）**。方式は軍事征服、小国懐柔、大国合併を区別する。具体的な量と期間は暫定値として実装し、公式ゲームの忠誠範囲に合わせて実機で調整する。

Q86 は **偉人と総督を産出へ資産化しない**。本人の個体・固有能力・行動回数、人物としての記録を保持する。離脱後に再獲得する場合も同じ規則を適用する。

万世紀では Heroes & Legends を必須とし、公式既存の英雄を出さず独自の戦国英雄を使う。生存英雄と再召喚権の移管は公式の英雄管理表・召喚元と個体を検証する。権利の継承が確認できない場合は理由を記録した自害として扱う。単なる「移管したはず」の記録では成功としない。

#### 三段階判定の暫定規則

以下の数値は PoC の暫定値であり、実機結果を受けて調整する。各資産を安定した ID 順に処理し、判定ごとに公式ゲームの乱数を `0..9999` で一度消費する。乱数のラベル・生値・検証用の適用値を保存する。読込、再送、画面の再表示では既存の値を使い、再抽選しない。マルチプレイでは検証用の強制値を使わない。

| 吸収方式 | 一次離脱率 | 選択行為の成功率への補正 | 都市移管時の忠誠 | 文化摩擦 |
|---|---:|---:|---:|---:|
| 軍事征服 | 24% | -7ポイント | -15 | 3手番、毎手番-2 |
| 小国懐柔 | 14% | 0ポイント | -5 | 2手番、毎手番-1 |
| 大国合併 | 7% | +6ポイント | 0 | なし |

忠誠と関係値はそれぞれ `0..100` に制限し、未記録なら50とする。忠誠が50より1低いごとに離脱率を0.22ポイント、関係値が50より1低いごとに0.12ポイント上げる。高ければ同じ幅で下げる。保護・再契約中は5ポイント下げ、破約中は5ポイント上げる。品物の離脱率は算出後に4分の3を掛けて切り捨てる。行為が失敗した後の再判定は5ポイントを加える。離脱率の最終範囲は0〜95%。

| 選択行為 | 基礎成功率 |
|---|---:|
| 捕縛 | 88% |
| 登用 | 68% |
| 臣従 | 78% |
| 処刑・自害・部隊解散 | 95% |
| 保護 | 82% |
| 再契約 | 70% |
| 品物移管 | 94% |
| 略奪 | 88% |
| 接収 | 86% |
| 第三者への返還 | 90% |
| 部隊降伏 | 91% |
| 部隊編入 | 85% |
| 解放要素の継承・保存、宗教の保存 | 100% |

成功率には方式別の補正に加え、忠誠が50より1高いごとに0.15ポイント、関係値が50より1高いごとに0.10ポイントを加える。低ければ同じ幅で下げる。保護・再契約の補正は成功率にも逆向きに作用する。通常行為の最終範囲は5〜99%。解放要素と宗教の保存は補正せず100%とする。失敗後に離脱しなかった対象は、一般部隊なら降伏、人物・総督人格なら捕縛、Heroなら保護、偉人なら登用、品物なら接収とする。離脱の種類は、人物・総督人格が亡命・隠遁・離反・潜伏、Heroが潜伏・離反、偉人が亡命・隠遁・潜伏、品物が散逸。AI は人物・総督人格・偉人を登用、Hero を再契約、品物を移管、部隊を編入し、解放要素を継承する。

離脱した人物・一般Unit・品物は同一の個体 ID・能力・来歴を記録し、2手番後に野営地か集落の報酬として再登場させる。一般Unitも公式Unitの状態を保存し、再取得時に元の個体記録へ結び直す。未使用の既存地点を優先し、人物と一般Unitは野営地、品物は集落を優先する。同順位では元の位置からの縦横距離、次に区画番号で決める。地点がなければ未所有の空き陸地に集落を置く。日本のように陸地を事前配分した地図では、未所有地点の次に吸収側が持つ空き陸地を候補にする。都市・区域・既存の改善・部隊のいる区画を上書きせず、他の存続勢力が持つ空き区画には新しい集落を置かない。配置に失敗した地点は記録し、次手番に別の候補を試す。実際に地点が除去され取得者を確認した後だけ、その取得者へ一度だけ復帰させる。復帰先の公式 Unit や作品枠が使えないときは記録を保持して中断し、別個体の生成や二重付与をしない。偉人と総督人格は人物として復帰させ、産出へ換えない。

公式 Great Work は独自品物と同様に一作品ずつ判定する。作品の公式 index、種類、元の都市・建物・枠、創作者と効果を保持する。散逸・第三者への返還が確定した作品を吸収側の都市に残さず、公式の実体を枠から移して確認する。全ての旧国都市は吸収側へ移す。回収時も同じ index の公式作品を、取得者が所有する適合枠に一度だけ置き、元の実体が他国の枠に残っていないことを照合する。枠不足や中断では作品の所在と移動意図を保存し、複製して成功扱いにしない。移動手段の実機確認と実装状況は [勢力吸収 PoC](../../poc/absorption.md) に記録する。

通常の継承・略奪・接収で吸収先が保有する作品は、都市の所有者変更に伴う本体の移管を優先する。独立した作品移動を追加せず、元の都市座標・建物・枠に同じ原本が残ることを確認する。本体が首都の宮殿を置き換える場合だけ、原本を保全するために都市移管前の退避を行う。散逸・第三者返還・回収には、公式取引か、同一所有者内の公式作品移動と都市の所有者変更を組み合わせる。追加処理で借りた都市は元の所有者に返し、人口・建物・宗教・忠誠・領土・統治記録・中心部隊を保つ。要求の返り値や移動通知だけで成功とはせず、同じ原本の実枠、来歴、効果、世界で一件の所在を確認してから結果を確定する。

都市の忠誠値は公式ゲームの0〜100の範囲を使う。公式 `DLC/Expansion2/Data/Expansion1_GlobalParameters.xml` の扇動基礎値は-15、戦闘移管後は50、文化的帰属による移管後は100である。`DLC/BlackDeathScenario/Scripts/BlackDeathScenario_UnitCommands.lua` に `ChangeLoyalty` の実例がある。上表の値は、この規模を踏まえて置いた独自の暫定値である。

実機の Gameplay 側では都市の `ChangeLoyalty` を使える一方、`GetCulturalIdentity():GetLoyalty()` の読み取りは UI 側で公開される。都市移管後の UI キャッシュが更新されるまで政策の適用を待ち、適用前後の忠誠値と読取要求を保存して照合する。読取値が古い間は忠誠差分を再適用せず、効果の完了とも記録しない。文化摩擦は開始時に決めた手番数内で各手番に一度だけ適用し、読込で期間を延ばさない。

### 9.2 宗教の持続

- 宗教は発祥勢力が滅んでも即時消滅しない
- 世界の信徒が1人以上いる限り存続
- 公的施設を失っても、信徒・教典・遺物・聖地・亡命者が残れば地下化して持続
- 全世界の信徒が0になった時のみ失われた宗教状態へ移る
- 信徒0でも教典等が残る場合は「信徒なし」と「資料あり」を両方記録する。公的施設0なら地下持続の根拠も独立して保持する。表示は「失われた宗教」とし、地下化の記録や来歴を消さない（Q79の回答 a）
- 失われた宗教でも、教典・遺物・記録・人物が残れば再興可能
- 再興は信徒1人で始め、信仰20を払う。資料は使い切らず保有する。同じ資料も、再び信徒0になり再興の間隔を満たせば再利用できる（2026-10-01 16:07 JSTのオーナー回答）
- 資料の発祥国への返還で結ぶ宗教同盟の間は、相手の宗教が自国民を弾圧することも、自国が相手の宗教を弾圧することもできない。存続と実装範囲は9.3に従う
- 宗教は新しく作る。どのマップでも宗教は全部で20種とし、マップが広がるほど抽象化していく（例：日本マップでは宗派単位、アジア・世界マップではより大きなまとまり）
- 日本マップの20種は、次の実在の宗教・宗派11種とオリジナルの宗教9種とする
  - 神祇・社寺祭祀、天台宗、真言宗、禅（臨済・曹洞）、浄土宗、浄土真宗、日蓮宗、修験道、琉球祭祀、アイヌのカムイ信仰、カトリック（1549年以降のイベントで登場）
  - 神仏習合を踏まえ、神道と仏教を排他的な陣営として描かない。アイヌのカムイ信仰を「日本の神」と同一視せず、琉球祭祀を本土の神社制度にまとめない
- オリジナルの宗教9種、アジア・世界マップでの抽象化の段階、実在の宗教の表現方針（17.10）は未決

### 9.3 宗教再興

傾奇者、旅人、学者、芸人、探検家、盗賊、僧侶等が、遺跡・廃城・洞窟・沈没船・宇宙遺跡で失われた宗教の教典・遺物を見つけるイベントを持つ。

成果は再興、売却、秘匿、研究、異端化、他宗教への吸収、Artifact獲得、外交事件、英雄加入等に分岐する。

#### オーナーが確定した再興と発見後の選択

2026-10-01 16:07 JSTのDiscord回答を確定仕様とする。再興と8分岐は提案から削除し、次の効果を実装する。D8の内容は未決のため、PoCでは番号付き仮宗教を使う。公式APIの根拠と実機の確認方法は[宗教持続PoC](../../poc/religion-persistence.md)に記録する。

| 選択 | 確定した効果 | 前提・制限と資料の扱い | AIの第一候補 |
|---|---|---|---|
| 再興（b、資料は残す） | 信仰20を払い、信徒1人・公的施設0で開始 | 世界の信徒0、保有資料、自勢力の都市、生存する大勢力。資料を使い切らず保有 | 僧侶 |
| 売却 | ゴールド500を獲得 | 市場へ移管し、再利用不可 | 盗賊 |
| 秘匿（a） | 費用・産出0 | 後日の有料再興のために保有 | 他の候補が使えない場合 |
| 研究（bにEureka2件を追加） | 科学10・文化10と技術Eureka2件を獲得 | 都市と未研究・未Eurekaの技術2件が必要。資料を使い切る | 学者 |
| 異端化 | 信仰400を払い文化20を獲得 | 都市が必要。資料を使い切り、解釈と来歴を履歴に残す。新宗教・教義・信徒は増やさない | 芸人 |
| 他宗教への吸収（dを変更） | 信仰500を払い、その宗教を信仰する市民の3分の1を切り上げて自宗教へ移す | 原宗教と自宗教を標準宗教に対応付ける。吸収先は自勢力に信徒がいる存続宗教で、自分が創始した宗教へ変換。資料の移管と来歴は保持し、再利用不可 | 第一候補が使えず吸収先がある場合 |
| Artifact獲得（a） | 文化30を獲得し、PoCのVaultに1件収蔵 | 都市が必要。勢力全体で生涯1枠。標準Great Work・観光・同調効果は付けない | 探検家 |
| 外交事件（返還） | 発祥国へ資料を返し、同国が現在持つ外交的支持と金の半分を同国から受け取り、宗教同盟を結ぶ | 生存する他国の発祥者と接触済み・平和時。資料は返還先が保有し、報酬への再利用不可 | 旅人 |
| 英雄加入（dを変更） | 公式の英雄1人が加入し、実行直前の毎ターンの信仰創出量の10倍を信仰として獲得 | 公式Heroes & Legendsモード必須。自都市の公式の英雄拠点建物と未加入の英雄が必要。PoCで勢力全体の生涯1人。加入費用なし | 傾奇者 |

- 教典・遺物・記録・人物のいずれでも再興できる。宗教ごとの間隔は10ターン以上。新しい集団のIDは既存記録を上書きしない空きを選ぶ。再興済みの同じ資料も、信徒0と間隔と信仰20の条件を満たせば使える。資料があるだけでは自動再興しない
- `canRevive`は再興に使える資料が残っていることを示す。都市・費用・間隔は実行時に検査する。発見は1件につき1選択。未解決の発見資料で再興する場合は、その発見の再興選択を解決し、直接再興では発見記録を未解決のまま残さない。再興以外は勢力×宗教×分岐ごとに1回まで。資料を削除・移管・再発見しても履歴を残す
- 研究はEurekaの定義があり、未研究かつEureka未発生の技術を技術名の識別子順に並べ、先頭2件を選ぶ。2件に満たなければ実行不可。UI専用の`CanTriggerBoost`は使わない
- 吸収の人数はGameplayの`City:GetReligion():GetNumFollowers(religionIndex)`を世界中の生存勢力の都市について合計し、合計を3で割って1回だけ切り上げる。都市ごとに切り上げず、市民を移住させない。プレイヤーID・都市ID順に変換人数を割り当てる。圧力変更後に元宗教の減少・自宗教の増加・他宗教の人数不変を再読取で検査する。宗教別の圧力消去と丸めは要実機確認
- 標準宗教との明示的な対応付けがある場合、存続・喪失・再興の判定には実際の市民信徒数を使い、台帳の入力だけで存続中の宗教を失われた扱いにしない。吸収では1人以上の変換が必要で、0人なら費用を払わない。資料の発見は信徒0の間に行い、その後ほかの集団が再興しても、保有する資料から再興以外の選択を解決できる。対応付けた宗教の再興では自都市の無宗教の市民を優先し、いなければ宗教ID順で1人を変換する
- 外交的支持はエンジンで整数のため半分を切り捨て、奇数の残りは返還先に残す。金は半額を移転し、端数を丸めない。追加の金や支持を無から生成しない
- 宗教同盟の終了規定はこれまでなかったため、外交上の同盟・平和状態に連動させる。同盟の期限切れ、宣戦による平和の終了、どちらかの滅亡で制限を終了する。ターン開始と制限の照会時に確認し、終了記録を保存する。通常の同盟を後日結び直すだけでは宗教同盟は復活しない
- 弾圧の効果量・実行コマンドはSSOTにまだ定義されていない。現時点では同盟状態と、相手の宗教から自国民への弾圧、自国から相手の宗教への弾圧を拒む`CanPersecute`／`AssertCanPersecute`を実装する。後続の弾圧処理は効果を適用する前にこの接続口を通す。標準ゲームの異端審問・宗教戦闘・通常の布教を自動で止める処理には未接続
- 英雄を使う箇所では公式Heroes & Legendsモードを必ず使う（8.4）。PoCの斥候による代用は廃止。未加入の公式英雄を英雄クラス名の識別子順に選び、公式の都市用加入Modifierを適用し、所有者・Unit・英雄クラス・寿命を確認する
- 科学・文化は一括産出Modifier、ゴールド・信仰・外交支持はGameplayの残高変更で適用する。速度補正は行わない。NotebooksのVault、独自の英雄固有技、自然な探索や宗教台帳と全都市の自動同期は後続の接続とする

AIは職業の第一候補から選び、使えなければ吸収→売却→研究→異端化→Artifact→外交事件→英雄→再興→秘匿の順に、人間と同じ前提・費用・制限を満たす候補を選ぶ。

効果を予約してからエンジンへ適用し、完了記録を保存する。途中で失敗した場合は処理中として保持して再実行を拒む。Gameプロパティと残高・Modifier・Unit生成は一括でロールバックできないため、失敗した処理は実際の残高・Unitと照合してから復旧する。ロード時に報酬を再適用しない。旧保存の効果未適用の選択も、自動で新報酬へ変換しない。

### 9.4 統治・正当性・自治

#### 都市と国

都市は国の構成単位であり、国ではない。都市と国の関係は、外交上の臣従や連邦ではない。

Civ6では、都市は文明に所属する。Loyalty は、今の所有者がその都市の支配層をどれだけ政治的に掌握しているかを、都市ごとに 0〜100 で表す。0まで下がり続けると、都市は帝国から離れ Free City になる。Free City は、中央政府に飽きた地方支配層が独立を試みた状態であり、強い国家アイデンティティは持たない。都市国家でもない。Civ6の都市は、食料や生産を国へ送る定義を持たない。各都市が自分の生産を持つ。

Civ7では、Settlement が文明の基本単位である。市民は境界内のタイルを働き、産出は帝国へ入る。入植地をすべて失うと、その文明は滅亡する。首都だけが最初から City で、以後の入植は Town である。

Civ7の Town は生産を持たず、City だけが生産する。この二役は採用しない。普通の県や州は、生産も支援もそれぞれが行う。

| 区分 | 国との関係 |
|---|---|
| 県・州・通常都市 | 自国の構成単位。生産も、余剰食料の送出も、救援の受け入れも行う |
| 小国 | 自国の外にある小さな国家。都市国家ボーナスの分配器ではない |

Civ7の接続は、他の入植地を通らない陸路、または同じ海域の水上施設と交易範囲である。ただし本プロジェクトでは、友好だから自動接続にはしない。接続は、建設された道路、港、飛行場などの物流施設があるときに成立する。文化・技術で道路不要のUnitが解放された場合だけ、そのUnitに限って道路なしの接続を認める。接続された県・州は、余った食料を飢餓地域へ送り、人員を災害地域へ出せる。

Happiness は地方と帝国の両方にある。地方の Happiness は専門家と建物を支える。帝国の Happiness は各入植地から積み上がる。地方が負けると産出が下がり、Unrest では購入、成長、方針変更ができなくなる。反乱を収められなければ、その入植地は失われる。征服した入植地は所有が移り、一定期間 Unrest に入る。

あなたが既に定義した内容との対応は、次のとおりである。

- 合致: Civ6の都市は食料も生産も国へ送らない。だから各都市が独立した組織に感じる
- 合致: 余った食料を他地域へ運ぶ主体が国である、という要求は、Civ7が入植地の余剰を帝国と接続先へ渡す構造と合う。ただし Town と City の二役は採用しない
- 合致: 道路や着陸場所がないと物流できない、という要求は、Civ7の「所有と接続は別」と合う。ただし Civ7 の自動接続は採用しない
- 合致: 接続が切れても独立国家にはしない。所有は国のまま残る
- 不採用: 生産都市と支援都市の二役。県や州は、各自で生産も支援も行う
- あなたの追加であり、Civ7にはない: 送り先は接続先一般ではなく、飢餓地域である。災害地域への人員派遣もある

出典: [Civ6 Loyalty](https://civilization.fandom.com/wiki/Loyalty_(Civ6))、[Civ7 Settlement](https://civilization.fandom.com/wiki/Settlement_(Civ7))、[Civ7 Dev Diary: Managing Your Empire](https://civilization.2k.com/en-GB/civ-vii/game-guide/dev-diary/managing-your-empire/)。

国家は都市の集合ではない。国庫、物流、人員派遣、救援、復興を行う統治主体である。ただし、その再分配は新しい外交状態ではなく、建設された接続の上で行う。

#### 国と他勢力

以下は都市と国の関係ではない。戦国の家、世界地図の国家、小国、解読後のAI、解読後の異宇宙勢力に使う。神は統治対象にしない。神の不満は、征服後の Unrest と同じく、都市の Happiness と Loyalty を下げ得る。

#### 小国懐柔

Civ6の都市国家は、小国として扱う。小国の定義は3.3に従い、**独立の有無を問わず面積10,000 km²未満の国**である。モナコ公国やバチカン市国は小国、ダゲスタン共和国は大国である。使節ボーナスを配る都市国家としては扱わない。

小国懐柔は、武力なしでその小国を自文明の都市として取り込む。操作は既存の都市国家画面に載せる。新しい画面は作らない。使うのは使節と、その小国が求める条件である。Civ6の都市国家は、使節1、3、6で種別ボーナスが開き、最も多くの使節を出した文明が宗主になる。本プロジェクトの取り込み条件は、その固定段ではない。

取り込みには、次の両方を満たす。

1. 領土の大きさに応じた使節を出す。初期値は、小国の保有タイル1つにつき使節1である。数値はバランス用であり、領土に比例するという意味は変えない。この使節数の算定は、3.3の**現実面積による小国／大国の分類とは別**である。1タイル未満の国も1タイル扱いなので、現行の初期値では必要使節は**最低1人**。要求条件はこれと別にすべて満たす必要がある。
2. その小国が求める条件をすべて満たす。条件は都市国家画面の依頼と同じ場所に出す。一つ達成して使節が1増える、ではない。

小国の都市国家画面と大国の外交画面では、既存の依頼・操作欄に条件、現在値、達成マークを並べる。小国では必要使節数と現在の使節数も示す。画面案にある国名と数値は配置の説明用であり、指導者の要求値を確定するものではない。

両方を満たすと、その小国の都市は自文明の都市になる。人物、宗教、Artifactは、吸収時の継承に従う。宗主ボーナスだけを受け取って小国を残す、では終わらない。

ただし、**既存の連邦関係などに属する小国の懐柔を、その相手国との関係を無視した即時吸収にはしない。**合意・離脱・関係解消など必要な前提と、相手国への外交上の影響は、関係宣言の権利義務とともに別途決める。相手国があっても規模分類は面積のみで判定する。

各国の指導者は、仲間になると Great Person になる。小国も大国も含む。Civ6の Great Person の多くは能力を使うと退役する。この指導者は退役させず、性格と特性を持った自国の人物として残す。

求めるものの型は、指導者の性格と特性から作る。効果の正本は日本語の中心イメージである。

| 要素 | 条件での役割 |
|---|---|
| 特性 | 何を求めるか。戦闘、信仰、科学、食料、調略など |
| 性格 | どう求めるか。数値の厳しさ、保証金の厚さ、条件の安定 |
| 外交状況 | 要求量を増減する。型そのものは変えない |

特性ごとの要求対象は、次を基準にする。

| 特性 | 求めるものの型 |
|---|---|
| 武人 | 戦力、防衛、統率できるUnit |
| 鬼神 | 決戦力、危機対応、短期の破壊力 |
| 策士 | 情報、調略、約束、工作の停止 |
| 魔神 | 異能、禁術、AI、変則技術 |
| 教者 | 教育、ジョブ、統治、成長支援 |
| 霊神 | 信仰、治療、防護、再興 |
| 凡人 | 食料、低コスト物資、安定した交易 |
| 天才 | 科学、暗号、発明、研究 |

性格は、この対象の出し方を変える。強気は数値を厚くし、温厚は薄くし、慎重は保証金と備蓄を足し、自由は条件が変わりやすく、忠実は一度出した条件を維持する。

#### 大国の合併

大国も、小国と同様に、その国の指導者によって定められた合併条件を持つ。条件を満たすと、武力なしで合併できる。ただし、多くの場合は高いハードルになる。

提示の例は、次のような複合条件である。

- 相手の生産量の2倍以上の生産力
- 相手の科学力の1.5倍以上
- 受け渡しの保証金として 50,000 Gold と 10,000 Faith

この数値は、すべての大国に共通する固定式ではない。指導者の特性が要求の主対象を決め、性格が厳しさを決める。友好度と外交状況によって、倍率と支払額は増減する。戦争、非難、非友好では増え、友好、宣言した友好、同盟では減る。増減の係数はバランス用であり、今は固定しない。

大国の指導者も、仲間になれば Great Person になる。合併条件を満たす前の相手指導者は、まだ自国の Great Person ではない。

#### 通常プレイへ接続する要求の暫定設定

PR116の製品接続では、現在配置する日本22勢力の国・指導者・日本語の性格と特性を、[要求設定](../data/absorption-product.json)に明示して生成する。この人物割当はゲーム上の暫定案であり、史実の人物の性格を確定したものではない。型は上の日本語の表に従い、英語の辞書義から効果を足さない。現在のCiv6の文明と指導者の組を両方照合し、登録されていない組を別の人物へ読み替えない。既存の人物記録に性格があればその日本語の性格を使い、特性の変更は拒否する。仲間にした指導者の人物記録と代理Unitにも、この性格・特性・国を残す。

現22勢力の分類用参照面積は、[面積表](../data/absorption-country-areas.json)にまとめる。Natural Earthの日本の陸地を、現製品の城の位置と領国の目印で配分し、正積投影上の1 km²の正方形で積分した暫定値である。ゲームのタイルや現在の保有タイルの数を使っていない。海岸線の資料のハッシュ、地理配分、時点、生成方法を面積表に保持する。現1534年地図が採用する地理配分の参照値であり、史実の直轄領の面積を確定するものではない。領土増減では再分類しない。世界851主体を省く決定ではなく、世界地図で配置する国・指導者・プレイヤーの全件対応は、その地図の制作で同じ明示入力へ追加する。

要求の数量は提示時に固定し、版を付けて保存する。暫定の基準は小国で相手の値の1.25倍、大国で1.5倍に要素別の下限を合わせる。武人は実際に統率する戦闘Unit数、鬼神は所有Unitごとの近接・遠隔戦闘力の大きい方の合計、策士は相手への公式外交アクセス、魔神は習得技術数、教者は都市人口合計、霊神は信仰創出量、凡人は都市の食料産出合計、天才は科学創出量を使う。鬼神の昇進補正、魔神の禁術・AI、教者のジョブ育成をこれらと同一扱いで確定しない。これらは現製品で読める日本語の型の暫定表現である。

性格の数量係数は勇敢1.1、冷静1.0、慎重1.15、陽気0.9、温厚0.8、強気1.4、自由1.0、忠実1.0。外交の係数は戦争1.6、非難1.4、非友好1.25、通常1.0、友好0.95、友好宣言0.9、同盟0.8とし、交戦中は開始を拒否する。忠実は提示した数量を維持する。自由は10手番ごとに0.9、1.0、1.1倍を順に使う。その他は外交状況が変わったとき、古い要求を取り消し、新しい版へ原子的に置き換える。既に一次判定を保存した開始意図と乱数は変えない。数値・下限・保証金額はすべて上の要求設定だけに置く。基準倍率は特性の主対象にだけ掛け、全員へ生産・科学・例示の50,000 Gold／10,000 Faithを一律に要求しない。係数は大国のハードルと性格の違いを動作確認するための暫定値であり、実機の進行を測って調整する。

冷静と強気は金の保証金、慎重は金と信仰の保証金を求める。金は小国100／大国1,000、信仰は小国20／大国100と相手残高の4分の1の大きい方に、数量係数を掛けて切り上げる。慎重は預託後にも金50の備蓄を残す。備蓄は保証金の支払済みの印ではない。保証金がある要求だけ、その他の全条件と使節がそろった時に受入国の残高から実際に引き落とす。引落し・返却の意図と処理前後の残高を先に保存し、本体の処理が変更後に例外を返しても、同じ額を二重に払わず再開する。関係のない残高へ変わり処理の成否を判断できない場合は、理由を残して停止する。

保証金は取込みが成立した時の費用として消費する。2026-10-06の[オーナー回答「保証金は消える」](https://discord.com/channels/1552944707464597524/1556810164886052954/1556849161884799038)に従い、三段階処理の結果と同じ当事者の資産移管完了を照合して、預託済みの金・信仰を消費済みにする。この時点では追加の引落し、返却、相手への譲渡を行わない。成立前の取消し・条件置換・不可逆な一次判定のない失敗では、実際に払った通貨だけを元の支払者へ返す。一次判定を保存した後は取消しを認めない。旧版で結果時の返却を始めていた保存では、既に返した分を再徴収せず、残る預託分を消費し、旧版の返却額を明示する。未確定の返却残高は停止して照合する。新しい精算状態は保存版2とし、旧版の書込処理に再決済させない。

受入国は公式の主要文明判定に合格する文明に限る。国・指導者の登録名や使節受取可否で主要文明を推測しない。吸収対象の小国は、主要文明と公式都市国家の双方を現実面積で分類する。主要文明の小国は同期したゲーム処理で受入国の未配属使節を1人減らし、独立した保存台帳へ配属を記録する。人間が公式都市国家へ送る通常のボタンは公式操作を保つ。AIは本体のプールを実際に1人減らして公式シナリオの付与APIを呼び、相手の受取Getterの正確な増分1を確認する。前後の値、消費、付与、完了を一つの記録に保存し、例外や再読込で二重に動かさない。別の増減や未保存の観測で成否が曖昧なら停止する。公式の初接触・政策による追加使節と、この明示的な1人の付与は同一操作として扱わない。必要数は現在の保有タイル数以上かつ最低1人とする。人間とAIは同じ人数・要求・実資金の条件を通り、AIは受入国ごとに条件を満たす一国へ毎手番1人まで送る。受入国と実際の手番を使う送付枠を、消費・付与の前に保存する。例外後の候補走査、同じ手番の再通知、保存の再読込でも別の使節を送らない。未完了の付与を次の手番に再開した場合は、再開した手番の枠を使う。取込み中の当事者へ別の要求を開始しない。両経路の本体挙動と保存・再開は、主担当による実機確認を要する。

画面は承認されたa案に従い、既存都市国家画面の一覧と依頼欄に、主要文明として配置した小国も出す。条件・現在値・達成印・必要使節を示し、大国は既存外交画面を使う。読取口は状態のコピーだけを公開する。登録・使節配属・取消しは同期操作で、実際の操作プレイヤーを受入国として再検査する。UIの条件、面積、関係確認済みの印は受け取らない。受付と結果画面は預託中・処理確認中・返却済み・消費済み・旧版精算済みを区別する。性格と特性の保存値は日本語の正本を保ち、受付・選択・結果・再読込は共通の翻訳キーで日本語・英語・ロシア語を表示する。関係行と条件入力はID順に固定する。開始前の失敗後に相手国が消滅した場合や旧保存の受入先が都市国家だった場合は、不可逆な一次判定がなければ保存した支払者へ実払分を返す。一次判定の記録がある吸収を取り消して判定をやり直さない。

受付は開始直前に両国を予約し、他の進行中の取込みや同時の開始処理と重なる計画を固定しない。Flowの記録がまだない失敗や旧版の待機計画は、条件を再読取してから開始する。既に一次判定の記録がある計画と乱数はそのまま再開する。ゲーム処理で使える同盟Getterを使用し、UI専用の外交状態と可視性は本体を読むUI関数から当事者と現在手番の値だけを取得する。公式都市国家の軍事徴発・和平・使節操作と元の依頼を保ち、吸収の登録・取消しは既存の依頼欄へ独立した操作として加える。

既存の1534年の主従・同盟と現在の第三国との同盟を再読取する。主従が初期同盟として表現されている間と、第三国との同盟がある間は開始を止める。保存する国間台帳には国別の確認済み状態と、連邦・保護・従属等の関係の存続を明示する。未確認や存続する関係を空の表で解決済みにしない。関係宣言の権利義務は引き続き未決であり、任意の同意ボタンを置いて関係解消を既成事実にしない。日本の関係が期限切れで解けた後は通常の外交を再読取する。

#### 指導者の進化

Great Person になった指導者は、進化コマンドで同名の Governor になる。進化後は、既定の Governor と同じ挙動で任意の都市へアサインできる。都市への定着、効果の開始、一度に一人の都市、という既存規則を新画面で置き換えない。

各 Governor は独自のスキルツリーを持つ。Civ6の Governor も、種類ごとに固有の昇進ツリーを持つ。一部のキャラクターは、Amani のように自都市以外へ派遣できる。Civ6の Amani の実際の派遣先は、戦争中でない都市国家だった。本作には都市国家がないため、Amani型 Governor の派遣先は敵国・他国の都市になる。派遣の可否や効果は Governor ごとのスキルで定義する。

#### 別モードの指導者選択

小国の指導者は、別モードでは通常の指導者と同じく、リーダーとして選択できる。トータルコンバージョン内の小国懐柔とは別の入り方である。

#### 終盤の独立宣言

- 終盤に国数が減ってきたら、治安や自治能力の影響を受けて、組織プレイヤーの加盟国や親国に属する勢力体が独立を宣言できる。治安・自治能力の定義と独立の条件は未決
- 実現方法は次の優先順で採用する。どれがCiv6で可能かは16.1の束3で検証する
  1. ゲームの途中でプレイヤーを増やす
  2. 滅亡した文明のうち、人間のプレイヤーでない文明の枠を、独立した勢力体の指導者・勢力に置き換える
  3. どちらもできない場合は、開始時に確保した予備枠（案Bの57プレイヤーと上限62の差）と、Civ6の自由都市で代用する

#### 合意による関係宣言

友好関係は、外交画面から直接宣言できる。Civ6の同盟と同じく、こちらが提案し、相手が同意したときだけ成立する。一方的な状態変更にはしない。

宣言できる関係は、次の4つである。

| 宣言 | 意味 |
|---|---|
| 相互保護 | 互いの防衛を引き受ける。支配関係ではない |
| 従属国 | 一方が他方に従う。両者の同意が必要 |
| 植民地国 | 一方が他方の植民地となる。両者の同意が必要 |
| 連邦関係 | 共通の対外関係を持つ。内政は各自 |

世界マップの**国間の初期関係は、判定日時点の史実に沿って事前設定**する。連邦の構成主体は、面積による規模分類とは別に中心国と連邦関係で開始する。例えばロシア連邦とダゲスタン共和国は、別々のゲーム上の領土・指導者を持ち、ダゲスタンは大国として初期連邦関係でロシアと結ばれる。初期設定はゲーム開始時の関係の記録であり、プレイ中に新たな連邦関係を提案する際の**両者合意**を省略する例外ではない。連邦でない自治領・構成国まで機械的に「連邦」とは呼ばず、それぞれの実態に合う初期関係を記録する。関係の具体的な権利義務は別途議論する。

この4つは、合併でも懐柔でもない。両国は残る。連邦関係で初期配置するだけでも、相手の指導者は自国の Great Person にならない。仲間になるのは、懐柔、合併、またはそれ以外の加入である。

これは、以前の9状態を一括して復活させるものではない。旧案には同盟と一方的な統治形態が混在していた。今回定めるのは、両者合意の関係宣言である。取り込んだ県・州を直轄や自治に分ける仕様にはしない。

軍事征服は残す。ただしマップ攻略の必須条件にしない。小国は懐柔、大国は合併条件で取り込める。爆撃機、戦車、核による最速軍事だけが、マップを終わらせる唯一のルートになってはならない。

#### 関係状態は未決

独立、同盟、保護、自治、臣従、連邦、直轄、統合、反乱の9状態は、確定ではない。小国懐柔と大国合併を入れた結果、役割が重なっている。

| 旧案の状態 | 今の仕様との関係 |
|---|---|
| 統合 | 大国合併の結果であり、選ぶ状態ではない |
| 保護、臣従、自治、連邦、直轄 | 取り込んだ県・州を特別な統治形態に分ける。県や州が各自で生産も支援も行う、という定義と衝突する |
| 独立、同盟 | Civ6の既存外交で足りる。合併条件の増減に使う |
| 反乱 | 残す価値がある。ただし新国家ではなく、Free City と同じく地方支配層が中央を拒否した状態 |

現時点の案は、新しい9状態を採用しないことである。外交状況は Civ6 の既存関係を使い、取り込みは小国懐柔と大国合併の結果だけにする。取り込んだ都市は、普通の県・州になる。

合併せずに共存する関係は、相互保護、従属国、植民地国、連邦関係の4宣言で定める。Civ6の同盟以外を追加する、という残論点はこれで閉じる。

以下の3値、憲章、遷移表、9状態の表は、旧案である。9状態を採用しない限り、仕様にはしない。

#### 旧案: 3つの値

値はそれぞれ 0〜100 とする。一つの忠誠値にはまとめない。この表は未採用である。

| 値 | 持つ単位 | 見ているもの |
|---|---|---|
| 国家正当性 | 国家に1つ | その国家が、約束した統治を果たしているか |

#### 旧案: 憲章

自治、臣従、連邦、保護には、例外を最大2つまで付けられる。自由な権限スライダーは作らない。

- 宗教保全
- 任命保全
- 税率固定
- 非駐留

憲章を破ると勢力信頼が大きく下がり、関係状態は1段階緩む。破約はNext Actionになる。

#### 旧案: 遷移

より強い支配への変更は自動では起きない。プレイヤー、または方針の範囲内の国務長官が提案し、不可逆な統合・処遇・宗教抑圧はプレイヤーが承認する。

初期値は次のとおり。数値はバランス用の初期値であり、状態の意味は変えない。

| 遷移 | 条件 |
|---|---|
| 保護を維持 | 防衛義務を果たす。失敗すると独立へ戻り、勢力信頼が下がる |
| 直轄を維持 | その地域へ救援または物流が届く。届かない年は地域安定度が下がる |
| 自治・連邦を維持 | 現地が自給する。宗主の備蓄流入は直轄より少ない。供給失敗だけでは安定度を下げない |
| 直轄への変更 | 勢力信頼60以上、地域安定度50以上、現状の状態を5年維持。軍事占領でも実行できるが、その間は信頼が上がらない |
| 統合 | 勢力信頼80以上、国家正当性60以上、直轄または連邦を10年維持、プレイヤー承認 |
| 反乱予兆 | 地域安定度25以下。Next Actionを出す |
| 反乱 | 地域安定度10以下、かつ勢力信頼30以下。両方を満たしたときだけ発生 |

飢餓救援、災害復興、医療支援が届くと、対象地域の安定度が上がり、国家正当性も少し上がる。届かない飢餓と災害は、その逆になる。これが、都市最適化ではなく国家運営が正当性に効く理由である。

処刑、Artifact略奪、憲章外の宗教抑圧は勢力信頼を下げる。信頼が低くても地域が安定していれば、反乱ではなく離反、工作、亡命としてNext Actionに出る。

### 9.5 暗殺者Unit

暗殺者Unitは、Civ6のスパイのように成功を確率判定するUnitである。「スパイと同じ計算式」を使うとはまだ決めない。暗殺者はマップ上のUnitとして道を歩いて対象へ向かい、都市にもUnitにも使える。対象はあらゆる人物・Unitで、暗殺者が暗殺者を暗殺することもできる。

本節のターン数（育成所要時間、再育成ロック、任務期間、コマンド待機）はすべて通常速度の値であり、他のゲーム速度では1.3の換算規則に従う。

#### 育成と再育成の制限

- 通常の育成所要時間は100ターン。外的要因によって増減するが、どれほど有利でも**20ターン未満では育成できない**。通常速度のターン数であり、他のゲーム速度での扱いは1.3の換算規則に従う
- 育成所要時間を増減させる外的要因は、諜報系の建物・区域、政策・政体、育成都市にいる武将の特性・ジョブ、自国の治安、外交関係とする。治安は、良いほど育成が長くなり、悪いほど短くなる（治安が悪いと裏社会の人材が増えるため）。外交関係も育成に使うことは2026-10-01のオーナー決定である
- 外交関係の参照先と補正量は暫定値で検証する。育成開始時には任務先がないため、`TrainingRelation="WORST_ALIVE_MAJOR"` として自国を除く存命主要国の最大敵対度を毎ターン使う。相手がいない場合と全相手が友好的な場合は補正0。既存の任務待機と同じ関係尺度（-1が最良、1が最悪、戦争時1、外交台帳の友好度も反映）を使い、0〜1へ制限した敵対度に `ProductionRelation=10` を掛けて短縮する。敵対する国があるほど育成人材の需要が増えるという仮説を、任務待機と同じ最大10ターンの補正で検証する。参照方式と係数はオーナーの確定値ではない
- 暗殺者を育成できるのは、同時に1都市だけとする。どこかの都市で育成中なら、他の都市では着手できない
- 暗殺者の**育成完了から10ターン**経つまで、次の暗殺者を**国全体のどの都市でも育成できない**。都市ごとではなく全国共通の育成ロックであり、途中で育成先を変えても回避できない
- 育成所要時間と再育成ロックは別の時計。育成に着手できる時点を縛るのであって、既に育成したUnitの任務実行を直接縛るものではない
- 育成期間の補正は、開始時に固定せず、毎ターンの現在の治安・関係・建物などから再計算する。条件が変われば完成予定ターンも前後する。通常100ターン・最低20ターンを保ち、再計算では乱数を使わない。開始ターン、速度換算、育成する都市と各補正の入力を保存し、読み込み後も同じ条件なら同じ期限になる
- 作る操作は日本語で「育成」、英語で train / training、ロシア語で「подготовка」と呼ぶ
- 20ターン下限の例外は現時点ではない

#### 対象と難易度

| 対象 | 基本成功率 | 備考 |
|---|---:|---|
| 他国の指導者 | 1% | 「超ごく稀」。量産可能な勝ち筋にしない |
| 敵国のGovernor | 15% | |
| 敵国のGreat Person | 30% | |
| Hero | 50% | |
| Unit（暗殺者を含む） | 50% | |
| Builder系のUnit | 90% | |

基本成功率には、治安・対象国との関係・護衛などの補正を掛ける。他国の指導者は、戦争中かどうかにかかわらず対象にできる。

#### 実行の流れ

1. 暗殺者Unitを対象の近くまで移動させ、暗殺コマンドを実行する。結果が出るまで複数ターンかかる
2. 任務期間は、対象ごとの基準（Great Person 2ターン、Governor 3ターン、指導者 5ターン）に、暗殺者の現在地から対象までの距離の倍率（近距離×1、中距離×1.5、遠距離×2、端数は切り上げ）を掛けて決める。Hero・Unitの基準は未決
3. 成否は**コマンド実行時に決めてセーブに保存し**、任務終了時に結果を出す。セーブの再読込で結果は変わらない。マルチプレイでも各端末で結果がずれない
4. 暗殺コマンドは、前回の**自国によるコマンド実行から基準50ターン**が経過するまで、**国全体のどの暗殺者Unitでも**再実行できない。Unitや対象国を変えても回避できない
5. この待機は、自国の治安が悪いほど、対象国との関係が悪いほど短くなり、暗殺者訓練所、暗殺系のGovernorスキル・Heroスキル・Great Personスキルでも短くなる。下限は1ターンで、治安が最低、対象国との関係が最低、暗殺者訓練所があり、暗殺系のGovernor・Hero・Great Personのスキルをすべて合算したときに、ようやく1ターンに届く
6. 自国の暗殺任務が1つでも進行中の間は、別の暗殺者Unitでも次の任務を始められない
7. コマンド待機は暗殺者の育成所要時間・国全体の再育成ロックとは別管理。任務が成功しても失敗しても、コマンド実行時点を起点として待機する
8. 任務終了前に実行した暗殺者Unitが失われた場合、成功・失敗・発覚の結果をすべて取り消す。ただし、実行時に固定した友好度低下・不平増加の罰則を一度だけ適用し、全国コマンド待機は維持する。捕縛・死亡、開戦理由、第三国の非難は起こさない
9. 成否と発覚は別に判定する。失敗と発覚には、それぞれ共通のペナルティと独自のペナルティの両方がある

| 区分 | ペナルティ |
|---|---|
| 共通（失敗・発覚） | 対象国との友好度の低下、Grievances（不平）の増加 |
| 失敗のみ | 暗殺者Unitが捕縛または死亡する |
| 発覚のみ | 対象国が正当な開戦理由を得る。他国からも非難され、世界会議の非難議題になり得る |

Civ6のスパイでも、任務に失敗して未発覚の場合や、捕縛・死亡の場合がある（[Civilopedia: Spies and Espionage](https://www.civilopedia.net/en-US/gathering-storm/concepts/diplo_5/)）。発覚した諜報活動がGrievancesを生む点も参照する（[Grievances (Civ6)](https://civilization.fandom.com/wiki/Grievances_(Civ6))）。

#### 指導者死亡後の国家の行方

暗殺成功によって指導者が死亡しても、対象国の全国土を実行者が自動取得することはない。**暗殺コマンドを実行した時点のその国のステータスと周辺状況**に応じて、次のいずれかへ分岐する。自由国家分岐は、各都市がCiv6の自由都市へ分裂するものとする。これは2026-10-01のオーナー回答「1c」による定義の決定である。

| 分岐 | 結果 |
|---|---|
| 自由国家 → 自由都市へ分裂 | 全都市をエンジンの自由都市枠へ移す。旧国の全マップUnitは解散し、存命人物は元の家の登録簿とGameの履歴に無所属として残す。旧枠は資産を失い、本体の通常の敗北処理に委ねる。都市はFree Cities AIが操作し、再統合は本体の忠誠心による転向や都市の再取得に従う（1c） |
| 隣国による吸収 | 国力、友好・同盟、共有国境と距離、取得できる宗教・文化の近さを合わせて受入国を選ぶ。全都市を移し、旧国の全マップUnitを解散する。存命Great Person・武将・Governorは人物登録簿へ加入し、死亡指導者は復活させない。受入国の外交を維持し、旧国の戦争・条約を新規コピーしない（「2aとcなどの様々な要素により決まる方がいい」） |
| 世界会議の投票 | 公式の世界会議／外交支持による投票で処遇を決める。3.2により世界会議が無効な日本では、Gameplayの `Player:GetDiplomacy():GetFavor()` による外交支持を重みにした代替採決を行う。日本の世界会議能力は復活させず、朝廷・将軍の裁定とは別に扱う（3b） |
| 後継者の自動継承 | 登録済み存命候補を血縁優先、同順位は人物ID順で選ぶ。同じ国・外交・都市・Unitを維持し、指導者になるGreat PersonのマップUnitは除去、Governorは人物登録から退役させる。兼任させない。非血縁で提供済みの国名がある場合だけ改名する（4a） |

分岐は、存命の後継候補の有無、当該国の治安・都市や地域の状況、隣国の強さと関係、会議または代替採決の有無などの条件で各分岐の重みを変えた抽選で決める。分岐、受入国、後継者、採決の参加国・票・外交支持・集計結果を暗殺コマンドの実行時に固定して保存する。資産処理は任務終了時の現存都市・Unitを対象にする。固定した受入国や後継者が解決前に失われた場合と採決同点時は、暫定の `MissingRecipient / MissingSuccessor / CongressTie = FREE_STATE` により自由都市へ分裂し、選び直さない。分岐の抽選重み、以下の係数、正式世界会議の議題・参加手続、ネイティブ指導者・Governor効果の交換はなお未確定・未接続の範囲を持つ。

#### 受入国の採点と日本の代替採決（係数は暫定）

方針は2026-10-01のオーナー決定である。数値はPoCの名前付き暫定定数であり、オーナーが確定した値として扱わない。

- 受入候補は、共有する領土の境界がある、または都市間の最短距離が `NeighborDistance=6` 以内にある存命主要国。実行者もこの条件を満たす場合だけ候補になる。
- 国力の原値は `都市数 + 軍事力 / RecipientMilitaryPerCity`。`RecipientMilitaryPerCity=100`。Gameplayで軍事力の読取APIがない場合は都市数のみを使う。候補間の最大値（下限1）で割って0〜1へ正規化する。
- 友好は `(1-敵対度)/2`。同盟なら1、戦争・敵対度1なら0を優先する。敵対度は通常の関係入力と暗殺の友好度罰則から得る。共有国境は、対象国の所有タイルと相手国の所有タイルの間の辺数を候補間の最大値（下限1）で割る。距離は `max(0,1-最短都市間距離/NeighborDistance)`。
- 宗教は双方の多数都市宗教が取得できれば一致で1、不一致で0。宗教未設定・汎用のパンテオンは比較対象にしない。文化は提供された `CultureGroup` を優先し、ない場合は文明データの `Ethnicity` を弱い代理値として同様に比較する。この代理値を文化的同一性の確定判断にしない。未取得の項目は分母の重みごと除外する。
- `RecipientWeights={Strength=35,Friendship=25,Border=15,Distance=15,Religion=5,Culture=5}`。**得点 = Σ（取得できた項目の重み × 0〜1の値）/ Σ（取得できた項目の重み）**。最大得点の国を選び、同点ならPlayer IDが小さい国を選ぶ。入力値・係数・各項目の値・得点・選定結果を保存する。
- 日本の代替採決は存命主要国の票を保存して集計する。暫定の票数は `CongressFreeVotes=1` に、外交支持で賄える追加票を加えたもの。追加票数kの仮の費用は `CongressFavorStep=10 × k × (k+1)/2` で、`k=floor((sqrt(1+8×max(0,Favor)/10)-1)/2)`。支持を重みに変換する方式であり、このPoCでは外交支持を消費しない。公式の票費用表と完全に同じと主張しない。
- 投票先は `Congress.Votes[Player ID文字列]` から受け取る。未入力時は暫定の `CongressDefaultBallot=ALLY_SUCCESSOR_RECIPIENT_ABSORPTION_OTHER_FREE` により、対象国とその同盟国は候補がいれば継承、受入国は吸収、その他は自由都市を選ぶ。成立しない案・無効票は集計せず、同点と全棄権は自由都市にする。`Congress.Enabled=false` のときだけ代替採決を除外する。通常プレイでも外交支持を読み、テスト専用の1国1票は使わない。

公式APIとファイルの根拠、実機で確認すべき範囲は [暗殺者PoC](../../poc/assassin.md#公式ファイルの根拠) に記録する。

#### PoCに適用するオーナー回答（2026-09-30、Q73〜Q78）

- 死亡後の国の行方は、コマンド実行時の状況から分岐と具体的な処理対象を決めて固定し、セーブへ保存する。任務終了時や読み込み後に抽選し直さない（Q73: a）
- 未決の任務期間・距離・補正・罰則の数値は、名前のある暫定定数に集めて検証を進める。仮の値を確定仕様にしない（Q74: a）
- 死亡後の四分岐を、都市、Unit、外交、人物、プレイヤー枠、AI、保存・読み込みまで具体化する（Q75: c）。具体案への2026-10-01の回答は本節の四分岐の表に確定決定として反映した。PoCの切替は `FreeState=ENGINE_FREE_CITIES / Absorption=WEIGHTED_NEIGHBOR_DISBAND / Congress=FAVOR_WEIGHTED_JAPAN_BALLOT / Succession=KIN_FIRST_SINGLE_ROLE` とする
- 暗殺者消失時は全結果を取り消し、固定の友好度・不平罰則だけを適用する（Q76: c＋罰則）
- 戦争中でない他国の指導者も狙える（Q77: a）
- 操作名は「育成」とし、育成期間の補正を毎ターン計算し直す（Q78: b）

実装と検査の記録は [暗殺者PoC](../../poc/assassin.md) に示す。日本の代替採決は正式世界会議の開催・議題送信・投票UIへ接続したものではない。Civ6本体の指導者交換・外交罰則・Governor除籍まで完成したという意味ではなく、未確認の範囲は同記録で明記する。

#### 文化圏ごとの名称

戦闘系Unit（4.6）の「暗殺忍者」は、日本側の暗殺者Unit名である。他国は、その国にふさわしく、史料や話者の確認ができた固有名を使う。無理に固有名を作らず、難しければ共通名「暗殺者 / Assassin / Убийца」を使う。下表は**採用確定リストではなく命名候補**であり、同一文化圏のすべての国へ一律に割り当てない。

| 対象（日本語） | 日本語名 | 英語名 | ロシア語名 | 採用上の注意 |
|---|---|---|---|---|
| 日本 | 暗殺忍者 | Assassin Ninja | Ниндзя-убийца | 日本側の名称 |
| 中国（候補） | 刺客 | Cike | Цыкэ | 古代中国の語。現代中国を含む全時代へ自動適用しない（[刺客](https://ja.wikipedia.org/wiki/刺客)） |
| 朝鮮半島（候補） | 刺客 | Jagaek | Чагэк | 韓国語の자객に由来。史実と時代適合を確認する（[韓国語の用例](https://namu.wiki/w/%EC%95%94%EC%82%B4%EC%9E%90)） |
| ニザール派関連の歴史勢力（候補） | ハシャーシーン | Hashashin | Хашшашины | 中東・イスラム圏全体の名称にはしない（[イスマーイール派研究所](https://www.iis.ac.uk/scholarly-contributions/assassin/)） |

各国の名称は用語辞書（14.3）で日英露を揃える。4.5の「特性英語名7文字以内」はUnit名には適用しない。文化・宗教集団の名を国全体に安易に当てず、表現方針（17章）を確認する。
