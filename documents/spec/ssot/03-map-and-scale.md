## 3. マップとスケール

### 3.1 日本列島

- 初回の日本統一までは、日本列島マップのみで遊ぶ
- 山地、海峡、内海、港、平野、鉱山、火山、街道、城郭立地を戦略要素にする
- 固定開始地点、時代別初期勢力、資源・遺跡・宝を配置する
- 初期の縦切り（MVP）は、1534年開始の日本列島全体の固定マップとする
- 日本マップでは、各勢力は指導者の史実に基づいた領土（城と周辺の土地）を持った状態で始まる。最初の開拓者（Settler）で都市を建てるところからは始めない。マルチプレイではこの限りではなく、通常どおり開拓者から始めることもできる
- 日本列島の陸地は、史実に基づいて日本マップに登場するいずれかの勢力に割り当てる。1534年の中小の領主の土地は、従っていた勢力か最も関わりの深い勢力に含める
- 日本マップの勢力間の境界は国境ではなく領土境とする。全勢力のユニットは、開放国境協定や宣戦布告なしに他勢力の領土を通行できる。通行権だけを与え、協定・外交状態・戦闘の規則は変えない。領土侵犯による外交ペナルティはこのマップで適用しない
- 城が密集する日本マップでは、Gathering Storm の近隣市民による忠誠心の毎ターン変化の上限を20から5（75%減）にする。総忠誠心・政策・総督などの個別の効果は維持する
- 日本マップでは城が密集しており、通常の Gathering Storm の忠誠心圧力によって都市が自由都市になる（反乱・独立する）ことは絶対に起こさない。特別なイベントや行動による忠誠心を理由とした離反は、後から別機能として追加できるようにする
- 日本マップ4種では都市間隔の `CITY_MIN_RANGE` を1にし、都市間2タイルを許す。万世紀で選べる通常の Gathering Storm 地図には適用しない
- 日本マップの選択肢は「万世紀」ルールセットでのみ表示する。通常の Gathering Storm の地図候補には含めない。万世紀では Gathering Storm の地図も引き続き選べる
- 開始時点は、織田信長の誕生日（天文3年5月12日）の状態とする。当主・城主・同盟関係はこの時点に合わせる
- 各勢力は、開始時点である程度栄えた状態で始める。城と守備隊だけの状態からは始めない。1534年の各家の規模（石高・動員力などの史料）に合わせて、人口・建物・区域・タイル改善・軍勢を置く
  - 領土の面積は今のまま変えず、石高の差は初期の財産（初期金・部隊・改善など）と資源で表す。本拠の人口は規模の階層に応じて6・5・4・3を目安にする
  - 規模の確度が低い勢力は、史料で確かめてから決め、それでも分からなければ推察で決める。琉球王国とアイヌも史料から推定する
  - 足利将軍家の本拠（京都）は、人口を6にし、寺社・商業を厚くする
  - 区域や改善を置く場所が足りなくても森は切らず、置ける分だけにする。戦略資源の備蓄は入れない
- 1534年の史実の同盟・婚姻・主従の関係と、敵対・不仲の関係を、開始時の外交状態に反映する。関係の機械可読データは [`spec/data/japan-1534-relations.json`](../data/japan-1534-relations.json)
  - 同盟・婚姻・主従は、友好宣言に加えて Civ6 の通常の同盟で表す。Civ6 の永久同盟は解消できず、期限でも終わらないため使わない
  - 敵対・不仲は、外交画面に出る好感度の減点（例：「1534年の因縁」）で表す
  - 史実の関係は、史実の領土で始める地図にだけ適用する。開拓者から始める地図には適用しない
  - 島津と琉球王国は友好で始め、同盟・婚姻・主従と同じく同盟にする（味方として扱う）
  - 固定キャラだけが出る日本マップなので、開始時から全勢力が互いに出会い済みとする
  - 全勢力の組の外交のアクセスレベルを、開始時から「限定的」にする。好感度の理由（因縁など）が最初から見える
  - 史実の同盟・婚姻・主従の家どうしと、島津と琉球王国（味方の8組）は、開始時から軍事同盟を結んでいる状態として扱い、視界を共有する（Civ6 の軍事同盟のレベル2の効果に当たる）
    - Civ6 はスクリプトから同盟の種類とレベルを設定できないため、通常の同盟に「全同盟で視界を共有する」特性（プンドメーカーと同じ）を味方の12家に付けて同じ効果にする。この特性は12家が後で結ぶ同盟にも効く
  - 味方の同盟は開始時だけのもので、強制はしない。Civ6 の通常の同盟の期限（30ターン）で終わったら、スクリプトで結び直さない。以後は通常の外交に戻り、各家が自分で同盟を結び直す（更新・新しい相手との同盟。戦国パックでは社会制度「誓約と同盟」で解放。AI は自分で判断する）。同盟が終われば視界の共有も終わる
    - これは「味方の同盟には期限を設けず、イベントでだけ終える」とした以前の判断を置き換える、後の判断である（オーナー判断 2026-09-30「最初だけ同盟で以降は強制的な同盟などを無くし、各自組み直しにしよう。」）
    - Civ6 はスクリプトから同盟をすぐに解けないため、裏切りなどのイベントで開始時の同盟を終えても、実際に解けるのは期限（30ターン）で終わるときである
  - 同盟中は、通常の外交では互いに宣戦できない。味方どうしが戦えるのは、同盟が期限で終わった後である
  - 因縁による好感度の減点は −10 から始め、時間では減衰しない。因縁は自然には消えず、和睦を促すイベント（ひらめきを与え、助言役のポップアップで知らせる）で解消へ導く
- 各勢力の本拠は、開始時点の史実の居所ではなく、その家の代表的な城に置く（例：伊達は米沢、織田は那古野、足利将軍家は室町殿）
- アイヌの指導者はタリコナとする。1536年の記録に残る道南西部の首長で、アイヌ全域の代表とするのはゲーム上の扱いである
- 島津家は島津貴久を当主とする1つの勢力にする。1534年の宗家と分家の対立は、イベントや内紛として表す

| MVP項目 | 内容 |
|---|---|
| 開始年 | 1534年（織田信長の誕生年）。戦国武将たちの幼少期から遊べるようにする |
| 範囲 | 日本列島全体（北海道・琉球を含む） |
| 大名家 | 伊達・蘆名（東北）、北条・山内上杉（関東）、武田・長尾（甲信越）、今川・織田・松平（東海）、朝倉（北陸）、足利将軍家・三好・六角・本願寺（畿内）、大内・尼子・毛利（中国）、長宗我部（四国）、大友・島津（九州）の20家 |
| 別枠の勢力 | 琉球王国とアイヌを、大名家とは別の独立した勢力として登場させる |
| Civ6のプレイヤー | 22（20家＋琉球王国＋アイヌ） |
| 城 | 各家の本拠と主要な支城で約50。開始時の所有者つきで一覧化する |
| 武将 | 各家3〜5人で約80人。当主・後継者（幼少の有名武将を含む）・重臣を中心にし、他の武将は成長やイベントで登場させる |
| 勝利 | 登録した全城（開始時の56都市。琉球王国・アイヌの城を含む）を支配すると天下統一。破却された登録城は条件から外れ、その跡地に建て直した都市も登録城として数えない。開拓者から始める版と登録城のない地図では、通常の Civ6 の制覇勝利と同じく全勢力の本拠（最初の首都）を支配すると天下統一。天下統一は1つの勢力で判定するが、ゲーム設定のチーム、1534年の開始時の同盟（味方8組。続いている間だけ）、勝利まで合算することを前提に組む「天下統一同盟」では城（開拓者から始める版と登録城のない地図では本拠）を合算する。チームではチーム全員が勝利し（Civ6 の勝者はチーム単位）、開始時の同盟と天下統一同盟では主体となる勢力だけが勝利する |

- 天下統一の合算の決まり（数値は暫定。実機の約200ターンの進行で調整する）
  - 開始時の同盟は組ごとに合算し、数える城の多い方（同数ならプレイヤー ID の小さい方）を主体とする。合算するのは開始時の同盟が続いている間（組の開始時の同盟の印が数値の間）だけで、上記のとおり開始時の同盟は結び直さないため、期限（30ターン）で切れたとき、またはイベントや交戦で終わったときに合算も終わる。期限切れの後に通常の外交で結び直した同盟は合算しない（天下統一同盟を組めば合算できる）。両家が同じ天下統一同盟に入っていれば、天下統一同盟の主体で判定する
  - 天下統一同盟は申し込んだ家が主体になる。人間の家は受諾で、AI の家は申し込んだ家と同盟を結んでいればその場で加わる。1つの家が入れる天下統一同盟は1つ
  - 天下統一同盟はいつでも抜けられる。同じ天下統一同盟の家どうしが戦争になると、主体でない側が抜ける（主体でない家どうしなら両方）。1家だけになった天下統一同盟は解ける。主体が滅亡するか抜けたら、数える城の最も多い参加者（同数ならプレイヤー ID の小さい方）が継ぐ
  - AI の家も天下統一同盟を申し込む。同盟を結んでいる相手と合わせて、数える城（または本拠）の30%以上を持つとき、ID の小さい相手から1家に申し込む。人間の家には受諾の画面を出す
- 1534年の越後は長尾家として登場させる。長尾家が上杉家を継ぐ出来事（史実では1561年）はイベントとし、条件を満たすと家名が上杉に変わる。Civ6はゲームの途中で文明の種類を変えられないため、Civilization IDは長尾家のまま変えず、表示名だけを切り替える
  - 文明名はゲームプレイ側の `PlayerConfigurations` では変えられない（セッターが無い。2026-09-28 実機確認）。UI 側で各画面の表示を上書きし、目標の家名は各端末が同期済みの共有状態（Game プロパティ）から読むことを設計要件とする。マルチプレイ時の同期・決定性は未検証（[PoC README「マルチプレイ同期と決定性」](../../poc/README.md#マルチプレイ同期と決定性)）。端末ごとの設定値は使わない
  - 影響範囲：文明名を出す画面ごとに上書きが要る（外交リボン、外交画面、ワールドランキング、都市バナーなど。同じ画面を差し替える他の MOD とは競合しうる）。家名は日英露の各言語で用意する。ロード後も共有状態から同じ名前を出す。マルチプレイでは全端末が同じ共有状態を読む。エンジンが組み立てる通知文など、UI の Lua を通らない文は上書きできない可能性がある（未検証）

### 3.2 時代パック

| 時代・モード | 主題 | 例 |
|---|---|---|
| 倭・邪馬台国 | 連合、祭祀、外交 | 卑弥呼、台与、ヤマト王権 |
| 飛鳥・奈良 | 律令、制度、宗教 | 推古天皇、聖徳太子、天武天皇 |
| 平安 | 朝廷、貴族政治、文化 | 桓武天皇、藤原道長 |
| 鎌倉・室町 | 武家政権、正統性、防衛 | 源頼朝、北条政子、足利尊氏 |
| 戦国 | 大名家、城郭、統一 | 信長、秀吉、信玄、謙信、政宗、元就 |
| 江戸 | 幕藩制、統制、都市経済 | 家康、吉宗、慶喜 |
| 明治・近代 | 制度転換、産業化、外交 | 明治天皇、伊藤博文 |
| 帝国期・戦後 | 近現代の国家運営 | 後段で慎重に扱う |

- 技術ツリーと社会制度ツリーは、Civ6 の公式のツリーを使わず、時代パックごとに完全オリジナルで作る。ユニット・建物・政体・政策の解放も各パックのツリーにつなぎ直す。最初は戦国パックから作る
- 戦国パックは、標準速度で約200ターン（1534年から1600年ごろ）を目安にする。天下統一するまでゲームを続け、時間切れやスコアによる勝利は置かない
- Civ6 の黄金時代・暗黒時代（時代スコア）は、戦国向けに作り直して残す
  - 時代の区切りは元号の改元に合わせる（1534〜1600年は天文・弘治・永禄・元亀・天正・文禄・慶長）。改元のたびに各勢力の黄金期・暗黒期を判定し、表示は「黄金期」「暗黒期」とそのまま呼ぶ
    - 慶長の後も史実の元号の順に改元し（元和・寛永から明治・大正・昭和・平成・令和まで）、改元のたびに判定する。令和は100年（2019年5月から2119年まで）続け、その次は架空の元号「遅代」にする。戦国時代のまま令和の後まで続くと日本が世界から遅れたままになる、という位置づけで、遅代の改元では点によらず全ての家を暗黒期にする（英雄期にはならない。暗黒期の政策の選択は通常どおり）。遅代はゲーム終了まで続く。改元の年月の表は [`../data/sengoku-reigns.json`](../data/sengoku-reigns.json)
    - 通常「XX時代」（XX Era）と表示される所は、今の元号で「弘治の世」「Kōji Era」のように表示する。元号と Civ6 の時代は同じもの（元号＝時代）で、改元のたびに Civ6 の時代も変わる。天文から遅代までの元号それぞれが1つの時代で、時代の長さはその元号の標準速度のターン数に固定する。技術・社会制度ツリーの時代の区切り（列の見出し）も元号の名前にし、各技術・社会制度は研究の目安の年の元号に属する。公式の新しい時代の画面は出さず、改元の画面が代わりに出る（[`../../poc/era-equals-reign.md`](../../poc/era-equals-reign.md)）
  - 時代スコアは独自の「武功の台帳」（Lua）で数え、本拠陥落・大名家滅亡・旧領回復に加え、支城の占領・同盟・史実イベントも点にする。ゲーム中に新しく結んだ友好宣言も同盟の区分で点にする（1点、同じ組は1つの期に1回。1534年の開始時の関係は除く）。期の長さは改元の時期に合わせて幅を持つ
  - 暗黒期は救済型にする（追加の罰はなく、専用の政策と、次の区切りでの逆転がある）。Civ6 らしい演出は残す。都市が多い勢力ほど黄金期が遠くなる公式の補正は残す
    - 暗黒期の政策を選ばない家（AI の家と、答えない人間の家）には、家ごとの既定の政策を使う。既定は家の史実の性格で割り当てる：武田・織田・長尾・島津は精鋭主義、毛利（村上水軍）・長宗我部・大友・琉球は海賊衆の免許、本願寺・足利・今川・朝倉・大内は寺院学問、残りは背水の陣。約200ターンの自動進行で偏りを見て調整する
  - 誓約は家ごとに固有のもの（信長の天下布武など）を作る。各家に固有の誓約を3つずつ作り、全家に共通の誓約は置かない
- 鉄砲伝来・キリスト教の伝来・検地のような史実の出来事は、史実の年に出来事として起きる。先に関係する研究を終えた勢力は、その年より早く使える。特定の人物・家に結びつく名前は、その家以外では一般的な名前で表示する（「太閤検地」は例外で、下記のとおりすべての家に表示する）
  - 史実の年が来たとき、関係する研究を終えていない勢力には、その研究へのひらめき（ブースト）だけを与える
  - 家名の切り替えは、長尾→上杉、松平→徳川、本能寺の変の後の織田→羽柴→豊臣を同じ仕組みで行う。どの家も、研究による襲名（下記）で切り替え、史実の年では切り替えない。長尾→上杉は社会制度 C16（朝廷・将軍への取次）、松平→徳川も C16 を研究したときに切り替わり、史実の年（1561年4月、1567年1月）にはその社会制度への着想だけを与える。以前の決定「長尾→上杉は1561年、または関連する社会制度を先に得る」は、この後の決定（オーナー判断 2026-09-30）で置き換えた
  - 織田→羽柴→豊臣は、Civ6 の研究の流れに合わせ、研究による襲名で切り替える。羽柴は社会制度 C16（朝廷・将軍への取次）、豊臣は C24（停戦裁定。関白の惣無事）を研究したときに切り替わる。史実の年（本能寺の変の1582年6月、豊臣姓の下賜の1586年10月）には切り替えず、その社会制度への着想だけを与える
  - 1573年の室町幕府の終わりでは、足利将軍家の勢力は残り、裁定の力だけを失う（他家どうしの裁定を発議できなくなり、当事者としては他家と同じ力で請求する）
  - 関ヶ原の戦いは入れない（天下統一でゲームが終わるため）
  - 「太閤検地」（社会制度 C25）は、研究したすべての家に「太閤検地」と表示し、家固有名にしない
  - 「天下布武」の持ち主は織田家とする（豊臣は勢力に無く、織田家が羽柴→豊臣に切り替わるため）。刀狩・楽市楽座・朱印状などは一般名のまま家固有にしない
  - 豊臣期の出来事「大坂城の築城」「北野大茶湯」は織田家の固有名とし、ほかの家では一般名（巨大城郭の築城・大茶会）で表示する
  - 同じ制度に史実の例が複数の家にある出来事は、家ごとに別の出来事にする。楽市は、六角の石寺新市（1549年）と織田の美濃・加納（1567年）の2件で、それぞれの家の研究で早まり、年には未研究の家にその研究への着想を与える
  - カトリック（キリスト教の伝来、1549年8月）は、関係する社会制度（C19 南蛮使節・C13 港町会合）を研究した家から広がる。地域の固定の順番では広げない。年が来たとき未研究の家には、その研究への着想だけを与える
  - 出来事で移った旧領（武田領の分割、北条領の徳川への移封など）は、城・資源の所有を自動で移さず、AI の攻略目標にだけ使う
  - 家固有名は、Civ6 が組み立てる通知文なども含め、持ち主の家には必ず固有名で表示する。一般名に倒れる表示は許容しない
  - 史実イベントは、暦の月までできるだけ合わせて起こす
- 1534年にまだ開発されていない資源（佐渡の相川金銀山など）は、最初は地図に現れず、技術の研究か史実の年の出来事で現れる
  - 港の交易アクセスの資源（平戸・堺の硝石）は、Civ6 と同じく研究で解放する（社会制度 C19 南蛮使節）。出来事の年（平戸へのポルトガル船来航の1550年）は、その研究への着想だけを与える
  - 資源を伴う出来事は、資源を直接置かない。出来事の年月が来たら、その資源が現れる研究へのひらめき（ブースト）を与える。資源は、その研究を最初の勢力が終えたとき、資源配置の年、または指導者の能力などで現れる（例：1589年の佐渡平定は西三川の砂金の研究へのひらめきを与え、砂金は研究の完了か1593年に現れる）
  - 戦国パックでも農園を使えるようにし、茶・絹・漆を改良できるようにする。金は鉄と同じく鉱山で改良する
  - 石見銀山（1526年）を開始時から置くため、銀は温帯の丘にも置けるようにする。佐渡の西三川の砂金は採用の 15 km の地図に置く（20 km は比較用で機能をそろえない：3.4）
- 戦国パックの1534年開始時は、全勢力に第I期の技術・社会制度の一部を共通で研究済みとして与える。琉球王国・アイヌを含む全22勢力に同じものを与える
- 公式ツリーを削除すると消える GS の仕組みは、次のとおり扱う（[連鎖削除の監査](../../poc/sengoku-tree-unlocks.md#公式ツリー削除に伴う連鎖削除の監査)）
  - 総督は、城主・奉行など戦国向けに作り直すまで無効にする。総督称号はどこからも得られないようにする（公式の社会制度・政府の広場とその建物・偉人・部族の村などの付与をすべて外す）。作り直しの中身は今後の課題（17章）
  - 丘陵の農場（棚田）は T01 用水普請から作れる
  - 開戦事由は、戦国の社会制度に付けた暫定の対応（C10・C11・C18・C23、近代以降の3種は最終の C30）のまま使う
  - 軍団・大軍団は T30 広域兵站で編成できる
- 戦国パックの暦は1534年から始め、ゲーム内では年だけを表示する（和暦の年月日は表示しない）
- 日本マップでは Civ6 の世界会議（世界法律）を行わない。朝廷・将軍による停戦裁定・所領安堵などの裁定として別に作る
  - 裁定は申請制で始める（朝廷からの自動の発議は当面入れない）。費用は金と正当性で払う。日本マップでは正当性が外交的支持（Favor）の代わりになり、裁定に外交的支持は使わない。裁定を拒んだ勢力には、正当性の低下と討伐の勅命の不利益を与える
  - 正当性は家ごとの 0〜100 の数値で、初期値は 50（足利将軍家は 70）。9.4 の正当性（旧9状態案）とは別の、日本マップの裁定の仕組み
    - 毎ターン増える：基本 +1、本拠（最初の首都）を保っていれば +1、室町幕府の終わりまでは将軍家と戦争していなければ +1（将軍家自身は裁定の力を持つ間 +1）
    - 変わる場面：裁定の請求で費用分を払う、裁定に応じると +5、拒むと -15、討伐の勅命で都市を攻め取られると1都市につき -10、勅命に参加して対象の都市を攻め取ると +10
    - 70 以上で全都市の金と文化 +10%、30 未満で全都市の金と文化 -10%（日本マップは忠誠度を常に最大に保つため、忠誠度ではなく産出に効かせる）。30 未満の家は裁定を請求できず、AI の家は裁定を拒みやすくなる（都市数で相手を上回るだけで拒む）
  - 裁定を拒んだ家は、10ターンの間、討伐の勅命の対象になる
    - どの家も参加できる。人間の家は裁定の画面のボタンで参加し、AI の家は対象と戦争中か隣接していれば自動で参加する
    - 参加した家は、期間中の戦争疲弊が減る。期間中に対象の都市を攻め取るたびに、金 200 と正当性 +10 を得る（外交的支持は与えない）
    - 期間が終われば、参加の記録と戦争疲弊の軽減も終わる
  - 足利将軍家は、人間が操作するときも含めて裁定を発議でき、1573年の室町幕府の終わりまでは裁定の力が3倍になる。3倍は停戦のターン数と、裁定を拒んだ勢力への不利益（正当性の低下と討伐の勅命のターン数）に掛け、請求の費用は3分の1にする
  - 裁定の費用・不利益・停戦のターン数・正当性の数値は暫定値とし、実機の約200ターンの進行で調整する
  - 世界マップでは従来どおり Civ6 の世界会議を使う
- 研究費・ひらめきの割合・政策・建物・ユニットの効果の数値は、PoC の実機で約200ターンの進行と22勢力の研究の進み方を測ってから決める。それまでは[ツリー設計案](../../research/sengoku-tech-civic-tree.md)の暫定値を使う

### 3.3 世界マップ

- 日本統一後に世界マップを解放する。世界マップにはCiv6既定の世界マップ（地球）を使い、独自の超巨大世界マップは作らない
- 日本の47都道府県を区別・表現する粒度は、世界マップではなく別に作る**アジア圏マップ**で満たす。アジア圏マップは、47都道府県を表せ、かつ近隣諸国も表せる粒度とする
- アジア圏マップでは、日本を複数タイルの県・都市圏・山地・港・島嶼・街道として表現する
- 世界マップには、制作時点で現存するすべての国を表す。国数を都合のよい一部に絞らない。小国も省略しない
- 独立国に加え、国として扱う非独立の連邦構成主体・構成国・自治領も個別に表す。独立の有無や面積を理由に、収録対象とした主体を省略しない。個別に収録する連邦州・準州等はゲーム上の国として扱い、それ以外の下位行政区画は別の国として二重登録しない。全件収録台帳には各政治主体の初期関係を記録する
- 対象判定の確実な下限は、国連加盟193か国（[国連加盟国一覧](https://research.un.org/en/unmembers/currentmembers)）と、非加盟オブザーバー国である聖座・パレスチナ国の2主体（[国連非加盟国](https://www.un.org/en/about-us/non-member-states)）。これは「世界の国は195だけ」と確定する意味ではない
- 台湾、コソボ、クック諸島、ニウエ、西サハラなど、国家性・承認・実効統治の扱いが異なる主体も収録台帳に必ず載せる。初期領土を持つ国・独立勢力・係争地のどの形式で表すかを個別に決めるが、無言で欠落させない。国・地域の統計コードは主権の認定ではない（[国連M49](https://unstats.un.org/unsd/methodology/m49/)）。判定日と収録台帳は別途確定する
- 各国は現実の国土・国境・主要都市・州／県・地域を基準に初期領土を持つ。領土の主張は各当事者が何を主張しているかという**国間・主体間の関係**に記録し、地図上では収録対象のうちできるだけ小さな地理的単位の主張を採用して単一の初期タイル所有者を定める。係争地では一方の主張を国際法上の確定事実とみなさず、採用した地図表現と根拠を明記する
- 収録する各国には最低1人のLeaderを登録する。小国のLeaderも別モードでは選択できる
- 世界マップ用の文明・Leader・人物は、原則として通常のCiv6モードでも選択可能にする

#### 面積による小国・大国と史実に沿った初期関係

世界マップで国として扱う政治主体は、独立の有無を問わず、**国土総面積が10,000 km²未満なら小国、10,000 km²以上なら大国**とする。独立・非独立は規模とは別の属性であり、現実の所属、連邦、保護などの関係は、**史実に沿った国間の初期関係**として定義する。非独立であることを理由に小国へ固定したり、独立の有無で同じ面積の分類を変えたりしない。

独立の状態を記録する際は、対象の政治主体が**公的に独立を宣言しているか**を確認する。ここでいう公的な宣言は、当該主体の政府・議会・それに準ずる代表機関による独立宣言、または独立を成立させた公的な法令・条約・国家設立文書を含む。「独立」という単語を使った文書だけを機械的に探すのではなく、その主体が独立国として成立した公的な根拠を確認する。個人・非代表集団による単なる主張は、この条件を満たさない。**国連加盟や他国の承認は、ゲーム内の独立判定の必須条件にはしない。**独立の判定は面積による規模分類と混ぜない。

「共和国」という名称や、連邦内の自治・国家主権を宣言した事実**だけ**では独立としない。宣言文に連邦の構成主体としての存続が明記されていれば、独立宣言ではない。例えば現行のダゲスタン共和国はロシア連邦の構成主体であり、1991年の国家主権宣言もロシアからの分離独立を定めていない（[ダゲスタン共和国の公式沿革](https://glava.e-dag.ru/historical-information/)、[主権宣言の分析](https://jamestown.org/russia-future-watch-iv-growing-rifts-between-moscow-and-dagestan/)）。ゲーム中では、独立の有無ではなく面積で規模を決め、ロシアとの初期連邦関係で所属を表現する。

| 国として扱う政治主体の現実面積 | ゲーム上の規模 | 独立・所属の記録 |
|---|---|---|
| **10,000 km² 未満** | 小国。小国懐柔の対象 | 独立・非独立のどちらもあり得る。現実に沿った初期関係を別に設定する |
| **10,000 km² 以上** | 大国。大国の合併条件の対象 | 独立・非独立のどちらもあり得る。現実に沿った初期関係を別に設定する |

レバノン（約10,452 km²）は大国、キプロス（約9,251 km²）は小国になる（[レバノン情報省](https://www.ministryinfo.gov.lb/en/2665)、[UNHCRのキプロス概況](https://help.unhcr.org/cyprus/country-information/foreign-embassies/)）。ダゲスタンは約50,300 km²なので**非独立の大国**であり、ロシア連邦との初期連邦関係を持つ（[ダゲスタン共和国の公式概要](https://glava.e-dag.ru/brief-reference/)）。連邦から離脱して独立しても、面積が変わらなければ大国のままである。公的独立を宣言しただけで領土を統治していない勢力は台帳・外交事件に残すが、領土を持つプレイ可能国としてはまだ配置しない。参照面積の基準日と出典、係争地の計上、戦中の領土増減で分類を動的に変更するかは未決。

**タイル換算は10,000 km²境界をゲームの地図へ投影する手順**であり、別の小国基準を作ることではない。同じ面積でも地図の縮尺や各タイルの現実面積が変わるため、まず各政治主体の現実面積を保存し、必要なUI・配置・使節数へタイル換算する。各タイルの現実面積が同じ局所スケールなら、\(N_{\rm country}=A_{\rm country}/A_{\rm hex}\) と \(N_{\rm border}=10{,}000/A_{\rm hex}\) を比較するだけで、現実面積による分類と同じ結果になる。**独立の有無にかかわらず同じ境界を適用する。**SSOTの「1タイル＝50〜150 km」は長さの目安で、幅・半径等の定義と地図の高密度化が未確定なため、現段階で世界共通の「何タイル以下なら小国」という整数には置換しない。例として正六角形の向かい合う辺間を \(d\) km と仮定すると、1タイル面積は \(A_{\rm hex}=\sqrt{3}d^2/2\) km²。\(d=50\) km なら10,000 km²は約4.62タイル、\(d=100\) km なら約1.15タイル、\(d=150\) km なら約0.51タイルである。これは**計算例**であってマップの確定仕様ではない。**1タイル未満になる国は、すべてゲーム内で1タイル扱い**とし、0タイルにはしない。これは表現上の下限であり、小国／大国判定の現実面積を1タイルの面積へ水増ししない。1タイル以上の端数の丸め方は、マップ制作時に決める。

バチカン市国は**小国**として確定する。現実の領土は約0.44 km²で、独立国のうち最小である（[バチカン市国の地理情報](https://www.vaticanstate.va/en/state-and-government/general-informations/geography.html)、[Britannica](https://www.britannica.com/place/Vatican-City)）。次に小さいモナコ公国は約2.08 km²であり、小国の例に含める（[オーストラリア外務貿易省](https://www.dfat.gov.au/countries/monaco/monaco-country-brief)、[Monaco](https://en.wikipedia.org/wiki/Monaco)）。3番目のナウル共和国（約21 km²）も小国に含める（[オーストラリア国防省](https://cove.army.gov.au/article/kyr-nauru-information)）。これらの国はタイル換算で1タイル未満でも**それぞれ1タイルとして扱う**。隣国の都市や領土と接する極小国の実際のタイル配置方法は、世界マップ制作時に調整する。

この分類は**ゲーム用の収録・操作上の分類**であり、国家承認や国際法上の地位を判定する宣言ではない。連邦構成主体を別の国として配置しても、それを現実に独立国と呼ぶわけではない。地図上の領土タイルには一時点で一つのゲーム上の所有主体を置く。構成主体のタイルはその主体に割り当て、中心国との所属は初期連邦関係に保持するため、同じタイルの二重所有は発生しない。現実の連邦国全体の面積とゲーム中の中心国が直接所有するタイル数は別のデータとして保持する。公的根拠が争われるケースでは、その根拠、帰属主張、実効統治の範囲、採用した地図上の表現を国別台帳に併記する。会話中の「大国側」は、元の帰属先が小国の場合にも適用できるよう「帰属先の国側」と読む。

#### 勢力体とCiv6のプレイヤー枠

Civ6のプレイヤー枠は、メジャー文明と都市国家を合わせて最大62である（詳細は `documents/research/civ6-modding-readiness.md`）。そのため、収録した政治主体（以下「勢力体」）と、Civ6上で1つの文明として動くプレイヤーを分けて扱う。

- 親国のプレイヤーに「属する」とは、その勢力体の都市・ユニットを親国のプレイヤーが操作するという意味である。勢力体としての区分・名称・表示は残り、独立や懐柔の対象にもできる
- 構成主体・海外領土・自治領（例：英国の海外領土、米国の州）は、親国のプレイヤーに属する
- 自由連合（MHL、FSM、PLW→米国、COK、NIU→ニュージーランド）は、相手国のプレイヤーに属する
- 係争主体（CYP-N、SOM-SL、GE-AB、GE-SOS、MD-TRN）は、主張している親国のプレイヤーに属する
- 国際組織（EUなど）は、加盟国をまとめて1つのプレイヤーにできる。旧ソ連地域は、判定日時点で現存する組織でまとめる（案BではCIS）
- 世界マップのプレイヤー枠は、`documents/research/player-grouping-candidates.md` の**案B**とする。EU、CIS、AU、アラブ連盟、ASEAN、CARICOM、SICA、Mercosur、CAN、PIF、SAARCの順に加盟国をまとめ、日本を含む主要22か国（日本、米国、中国、ロシア、インド、ブラジル、英国、フランス、ドイツ、豪州、カナダ、韓国、トルコ、イラン、サウジアラビア、インドネシア、南アフリカ、エジプト、ナイジェリア、メキシコ、アルゼンチン、パキスタン）は単独のプレイヤーにする。合計57プレイヤー
- 台湾（TWN）とコソボ（XKX）は、主張している国のプレイヤーには属させず、単独のプレイヤーとする。主張は関係データ（14.5）として残す
- 主役は常に日本である。そのため、同じ組織プレイヤーにまとめた国どうし（例：AUにまとめたエチオピアとエリトリア、スーダンと南スーダン）が互いに戦争・暗殺・懐柔できなくなることは問題にしない
- 勢力体ごとのタイル所有と主張関係（14.5）は維持し、プレイヤーへのまとめはその上に重ねる

#### 領土主張と単一タイル所有の割当規則

領有・帰属の**主張はタイルの追加所有権ではなく、主張する主体と対象地域を結ぶ関係データ**とする。対象の政治主体が公的に主張する範囲と、他の当事者による異なる主張、憲法上の帰属、承認、実効統治は出典・基準日を付けて併記する。「主張している」は「国際的に承認された」や「そのタイルを直接所有している」と同義ではない。マップのタイルには主張者を複数の所有者として重ねず、初期所有者IDを一つだけ設定する。

割当時は、まず**収録対象として独立した勢力IDを持つ最小の地理的単位**を優先する。国全体を対象とする親国の主張と、その内部の州・自治主体など範囲をより細かく特定した主体の主張が競合するなら、該当タイルは原則として後者に一意に割り当てる。親国による所属・領有の主張は関係データに残し、親国の直接所有タイルとしては重ねない。あくまで収録対象の政治主体間での優先順位であり、登録していない市町村を無制限に独立勢力へ増やす規則ではない。

複数の収録主体が**同じ細かさで互いに重なる範囲を主張する**場合は、国全体を一括で一方に塗るのではなく、証拠のあるさらに小さな地域・タイルへ分割して判断する。同じタイルでなお競合するときは、基準日時点の確認できる実効統治に従って初期所有者を一つ決め、相手方の主張は関係データに残す。実効統治も確定できないタイルは中立・未割当として監査に残し、根拠なく二者へ所有させたり、恣意的に一方の主張を消したりしない。極小国の最低1タイルも隣接主体の既存タイルを上書きする口実にはせず、必要なら地図の局所的な細分化で表現する。

小国・大国の判定は引き続き台帳に出典を示した**現実の主体面積**を使い、ゲーム開始時に直接所有するタイルの合計から再計算しない。親国の統計上の総面積と構成主体の面積を足し直して世界の陸地を水増ししない。領域主張の面積、台帳の分類用面積、実際に割り当てたタイルの面積はそれぞれ別の値であり、差異があるときは併記する。

### 3.4 距離スケール

Civ6本体に公式の「1タイル＝何km」はない。したがってマップごとに距離スケールを持つ。

| マップ | 1タイルの目安 | 表現するもの |
|---|---:|---|
| 戦国・日本列島全体（MVP） | 15 km（2026-09-29 オーナー決定。20 km 版は比較用として残し、機能はそろえない） | 城、峠、街道、瀬戸内海、港 |

- 日本の高密度表現はアジア圏マップと日本列島マップが担い、世界マップはCiv6既定の縮尺のまま使う

### 3.5 宇宙マップ

- 世界統一後、宇宙テックツリーと火星移住を伴う科学勝利で太陽系を解放する
- 地球、火星、月、惑星・衛星、軌道、宇宙ステーション、小惑星帯を開拓・争奪対象にする
- 太陽系統一後、天の川銀河、局所銀河群、ラニアケア超銀河団、宇宙へ進む
- 各段階で超未来テックツリーと文化／制度／思想ツリーを解放する
