#### 史実上の特別な関係・係争を個別確認した656主体

この節には英国の構成国、デンマーク王国の自治領、オランダ王国の構成国、自由連合を、すべてゲーム上の「連邦関係」へ機械的に言い換えない。関係名称は確認できた制度に沿って記録する。ロシアの共和国21件（ダゲスタンを含む）の初期連邦関係は[ロシア政府の憲法掲載](http://archive.government.ru/eng/gov/base/54.html)により確認した。面積は[共和国一覧の表](https://en.wikipedia.org/wiki/Republics_of_Russia/)を暫定資料とする。さらに29の有人の自治・海外領域、ベルギーとボスニアの6構成主体、北キプロスとソマリランドの2係争主体に加え、ドイツ16州とスペイン17自治州・2自治都市、カナダ10州・3準州、米国50州・首都連邦区、オーストラリア6州・ACT・NT・JBT、25か国群467の第一層区分、個別検証した自治・係争主体7件を収録した。通常の海外県・無人島を機械的に独立国へ昇格させない。クリミア・ドネツク・ルハンスクはここに無条件で加えず、[国連のウクライナ領土保全に関する記録](https://press.un.org/en/2025/ga12675.doc.htm)を踏まえて係争表現を別途行う。
