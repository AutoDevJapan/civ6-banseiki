# 14.4 国別台帳：地図化までの要確認主体（未編入）

#### 地図化までの要確認主体（未編入）

| 候補 | 三言語表示名（仮） | 見送り理由・初期関係 |
|---|---|---|
| VE-W | 連邦属領 / Federal Dependencies / Федеральные владения | [島嶼の集約で単独の自治政府・一つの領土区分を意味しない](https://en.wikipedia.org/wiki/States_of_Venezuela)。島別のタイルと行政権を確認する。 |
| SOM-NES | 北東ソマリア州 / North Eastern State of Somalia / Северо-Восточный штат Сомали | [ソマリア連邦政府は連邦構成州として承認](https://www.euaa.europa.eu/somalia-security-situation/27-sool-sanaag-cayn-and-north-eastern-state-nes)。ソマリランド・プントランドの主張と実効支配が重なり、排他的な地図面積を確定できないため規模判定を保留。 |
| SOM-PL | [プントランド](https://ja.wikipedia.org/wiki/プントランド) / [Puntland](https://www.euaa.europa.eu/somalia-security-situation/27-sool-sanaag-cayn-and-north-eastern-state-nes) / [Пунтленд](https://ru.wikipedia.org/wiki/Пунтленд) | ソマリア内の自治主体。ただし[北東ソマリア州とソマリランドへの主張が重なる](https://www.euaa.europa.eu/somalia-security-situation/27-sool-sanaag-cayn-and-north-eastern-state-nes)。公称面積を現在の非重複実効統治面積と同一視せず、境界判定を保留。 |
| SSD-ABY | アビエイ地域 / Abyei Area / Район Абьей | [南スーダン・スーダン間の帰属が係争中](https://unisfa.unmissions.org/en)。双方の面積やタイルを重ねず、共同管理・実効統治を別途確認する。 |
| SSD-GPB | グレーター・ピボール行政地域 / Greater Pibor Administrative Area / Административный район Большой Пибор | [南スーダンの州とは別の特別地域](https://mofaic.gov.ss/brief-history/)。重複しない境界と信頼できる面積値の照合待ち。 |
| SSD-RUW | ルウェング行政地域 / Ruweng Administrative Area / Административный район Рувенг | [南スーダンの州とは別の特別地域](https://mofaic.gov.ss/brief-history/)。重複しない境界と信頼できる面積値の照合待ち。 |
