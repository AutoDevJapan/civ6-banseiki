## 1. ビジョン

制作者は Civilization VI を約500時間プレイしており、バニラのゲーム体験には飽きている。

目標は、単なる指導者追加MODや日本文明のリワークではない。Civ6のヘックスマップ、ターン制、都市・領土・研究・外交・戦闘という技術的・操作的な基盤を活用しつつ、実際のプレイ感は別ゲーム級に変える。

### 1.1 コンセプト

**日本列島を舞台に、武将・家臣・職業ユニットを育成し、探索・装備・英雄・家名継承・周回を通じて日本統一を目指す。日本統一後は現実地理を基準にした超巨大世界、世界統一・火星移住後は太陽系、さらに銀河・銀河群・超銀河団・宇宙へ進出する、周回育成型の歴史・SFストラテジー。**

### 1.2 参照するゲーム性

| 参照作品・要素 | 取り入れる内容 |
|---|---|
| Civilization VI | ヘックス地図、ターン制、都市・領土、研究、政策、外交、戦争、ユニット配置、Hero、Great Person、蛮族、スパイ |
| 信長の野望 | 日本列島、大名家、城、家臣団、内政、外交、調略、領土統一、時代背景 |
| パワプロ | サクセス／マイライフ的なキャラクター作成、成長、選択、固有の育成結果、周回による引継ぎ |
| ディスガイア | 高いレベル上限、世代・継承による上限拡張、転職、ビルド、特殊技、組み合わせによる成長、世界法律 |
| ローグライト／収集ゲーム | パラレルワールド周回、限定的な記憶継承、探索、遺物、仲間、ビルド選択 |
| 宇宙SFストラテジー | 惑星・恒星系・銀河の開拓、異星勢力、AI反乱、超未来技術、宇宙規模の統一 |

### 1.3 時間の基本単位

- **通常速度では1ターン＝1年**として扱う
- 他のゲーム速度では、この基準を倍率換算する
- 75ターンの断片解読は75年、100ターンの完全解読は100年と解釈する
- 暗号解読、宗教の変遷、家名継承、国家プロジェクト、世界統一、宇宙進出に文明史としての時間感覚を与える
