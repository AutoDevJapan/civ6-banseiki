## 2. 全体進行と開始状態

### 2.1 解放チェーン

```text
日本列島・未統一
  ↓ 日本統一
世界・統一日本開始
  ↓ 世界統一
世界統一後の開始状態を解放
  ↓ 宇宙テックツリー解放 + 火星移住による科学勝利
太陽系マップを解放
  ↓ 太陽系統一
銀河系マップ／超未来技術を解放
  ↓ 天の川銀河統一
局所銀河群マップ／技術を解放
  ↓ 局所銀河群統一
ラニアケア超銀河団マップ／技術を解放
  ↓ ラニアケア超銀河団統一
宇宙統一マップ／終局コンテンツを解放
  ↓ 宇宙統一
ポスト宇宙統一・無限年代記
```

### 2.2 開始状態の選択

| 解放済み実績 | 選択できる開始状態 |
|---|---|
| 未達成 | 日本統一前 |
| 日本統一 | 日本統一前 / 日本統一後 |
| 世界統一 | 日本統一前 / 日本統一後 / 世界統一後 |
| 火星移住科学勝利 | 上記 + 太陽系開始 |
| 太陽系統一以降 | 上記 + 銀河以降の解放済みスケール |
| 宇宙統一 | 日本統一前 / 日本統一後 / 世界統一後 / 太陽系 / 銀河以降 / 宇宙統一後 |

- 世界統一後は「日本統一前」「日本統一後」「世界統一後」を常に選べる
- 宇宙統一後は、宇宙統一後を含むすべての解放済み開始状態を選べる

#### マルチプレイの分担

- マルチプレイでは、全員が日本側で遊ぶか、異なる勢力で遊ぶかをステージング画面（ゲーム開始前の設定画面）で選べる
- 全員が日本側で遊ぶ場合は、マップ開始前の設定で各プレイヤーの分担を決める。分担は、西日本・東日本・九州・北海道などのエリア指定、または都道府県名の指定で行う
- 日本側のプレイヤーの中から、勢力内のリーダーである「勢力主体」を決める。勢力主体は、世界会議などで日本としての決定権を持つ
- Civ6は1つの国を複数人で操作できないため、分担した各プレイヤーはCiv6上ではそれぞれ別のプレイヤーとし、同じチームに属させる

### 2.3 統一の四重の役割

日本統一、世界統一、太陽系統一、銀河統一、宇宙統一は、同時に以下を兼ねる。

1. そのシナリオの明確な勝利条件
2. 家名・プレイヤー記録として残る達成実績
3. 次マップ・開始状態・人物・技術の解放条件
4. 物語のエンディングと、裏ステージの入口

| 到達点 | エンディング後の主な裏ステージ |
|---|---|
| 日本統一 | 統一日本の反乱・遺跡・隠し武将・世界への航路 |
| 世界統一 | 統一地球のAI問題・宗教問題・異宇宙通信・火星移住 |
| 太陽系統一 | 異星文明の本国・未知の恒星系・銀河信号 |
| 宇宙統一 | 神の介入・異宇宙襲来・異宇宙遠征・統一宇宙の維持・創造観測 |

### 2.4 家名継承と別の歴史

周回は同一世界のやり直しではなく、家名・人物・勢力が一部の記憶を持つパラレルワールド体験とする。

- 用語は「転生」ではなく、**家名継承**、後継、記憶の継承、別の歴史を使う
- 継承対象は、最大レベル上限の一部、家伝、特性候補、Artifact持込権、解放ジョブ、人物図鑑、イベント記憶など
- 強い継承には、持込枠、コスト、敵の適応、難易度、イベント分岐などのトレードオフを持たせる
