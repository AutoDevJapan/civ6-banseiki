# 万世紀プールの第1弾データ

仕様の正本は [SSOT 4.7](ssot/04-factions-characters.md)。[JSON](data/banseiki-pool.json) は方向確認待ちの候補100人（史実20人・新規80人）を保存する。300人は拡張の目安であり、100人がゲームに登録済みという意味ではない。

## データの形

| 項目 | 内容 |
|---|---|
| schema_version | データの形の版。第1弾は1 |
| status | 第1弾は「方向確認待ち」。採用済み・解放済みと混同しない |
| target_size | 提案した共通台帳の人数の目安300 |
| characters | 人物100人の配列 |
| id | 固定人物ID。史実はJAC_POOL_H、新規はJAC_POOL_Oに3桁を付ける。別名・役職変更で別IDを作らない |
| name / reading | 日本語表示名と、かなで記した読み |
| origin | 史実 / 新規。新規は架空で、プレイヤーが作る自作キャラクターとは異なる |
| era / region | 活動の時代・主な関連地域。生年・出生地の断定ではない。第1弾は7時代・16地域を含む |
| faction | 関連する所属・出自。新規人物では架空家臣・架空組織と明記。全生涯の所属を網羅する項目ではない |
| category | 武将 / 英傑武将 / 軍師 / 僧侶 / 陰陽師 / 一般ジョブUnit |
| trait | SSOT 4.5の8特性から1つ。ゲームの設定であり史実の評価ではない |
| leader_candidate | 指導者として設計する候補かどうか。選択可能・実装済みの印ではない |
| existing_leader_id | 既存試作の同一人物のLeader ID。対応が無ければnull。毛利元就だけ既存の対応を記録し、現行SQLの万世紀の指導者22人と照合し、この第1弾と同一人物なのは毛利元就のみ。残りの指導者の台帳収録は拡張時に整える |
| description | 人物の短い説明。新規人物の出来事は架空の設定 |
| sources | 史実人物の資料記録。新規人物は空配列 |

史実の資料記録は `title`（資料名）、`publisher`（公開元）、`url`、`verified_on`（確認日）、`facts`（資料で確認した事実）を持つ。博物館・自治体・国立国会図書館等の公開資料で確認した。資料の画像は収録しない。創作の分類や特性を資料が裏付けるものとして扱わない。武将の幼少期・別名の詳細や海外の史実人物は、追加時にさらに調査する。

## 検査

```text
cargo run --locked --manifest-path tools/Cargo.toml -p civ6-data-rs --bin banseiki-pool-check
cargo test --locked --manifest-path tools/Cargo.toml -p civ6-data-rs --test pool
```

Rust検査は項目の形、100人と分類配分、史実20人と新規80人、人物ID・名前・既存Leader IDの重複、読み、時代・地域・特性、出典記録と日付、架空所属の明記、20家の架空家臣を検査する。出典の内容、名前の別表記が同一人物か、指導者として登録できるかは、この形式検査だけで確定しない。GitHubの既存Rustワークスペース検査からも実行される。

第1弾には、MVP20家の架空家臣を各家最低1人含む。架空人物の名前・背景・弱点は一人ずつ設定しており、既存指導者の定義を置き換えるデータではない。方向確認後に残りの人物・既存人物との対応・解放条件を追加し、MODへの接続と2人プレイの実機検証を行う。
