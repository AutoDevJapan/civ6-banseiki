# 万世紀プールの人物データ

仕様の正本は [SSOT 4.8](ssot/04-factions-characters.md)。[JSON](data/banseiki-pool.json) は初期収録300人（史実60人・架空240人）の台帳である。2026-10-07のオーナー回答aにより混合の方向が採用され、人物の選び方と史実の扱いは担当に一任された。

## データの形

| 項目 | 内容 |
|---|---|
| schema_version | データの形の版。現在1 |
| status | 採用済み。ゲームでの登録や動作の成否は別途検査する |
| target_size | 初期収録の目標300 |
| characters | 人物300人。配列の位置を人物の識別に使わない |
| id | 固定人物ID。史実はJAC_POOL_H、新規はJAC_POOL_Oに3桁を付ける。別名や役職変更で別IDを作らない |
| name / reading | 日本語名とかなの読み |
| origin | 史実 / 新規。新規は架空。プレイヤーが作る自作キャラクターとは異なる |
| era / region | 活動の時代と関連地域。生年や出生地の断定ではない |
| faction | 所属や出自。架空家臣・架空組織と明記する。全生涯の所属を網羅する欄ではない |
| category | 武将 / 英傑武将 / 軍師 / 僧侶 / 陰陽師 / 一般ジョブUnit |
| trait | SSOT 4.5の8特性。史実の評価ではなくゲームの設定 |
| leader_candidate | 初期300人は全員true。分類を指導者資格の制限にしない |
| existing_leader_id | 既存当主22人の元のLeader ID。それ以外はnull。既存人物を新しいLeaderとして二重に生成しない |
| description | 人物の短い説明。史実は資料で確認した事実、架空は創作の設定 |
| sources | 史実人物の出典記録。架空人物は空配列 |

出典には `title`（資料名）、`publisher`（公開元）、`url`、`verified_on`（確認日）、`facts`（確認した事実）を記録する。国立国会図書館・自治体・博物館の資料と、辞典の解説を参照した。没年や伝承の解釈に異説があるときは不確実性を残す。資料の肖像画像はこのJSONに含めない。

史実人物の分類・特性と、ゲーム上の開始母体となる文明は、史実の役職や国籍の断定ではない。世界・未来・宇宙の架空人物にも同じ形式を使う。22勢力の当主は既存の名前とLeader IDを照合し、同一人物へ対応づける。

## 配分と検査

武将120・英傑武将24・軍師36・僧侶30・陰陽師30・一般ジョブ60。地域は日本戦国140・日本の他時代60・世界60・未来地球圏20・宇宙20。日本8地域、世界6地域、未来・宇宙を含む。第1弾の人物IDと設定は保持し、指導者候補の印だけを全員trueへ更新した。

```text
cargo run --locked --manifest-path tools/Cargo.toml -p civ6-data-rs --bin banseiki-pool-check
cargo test --locked --manifest-path tools/Cargo.toml -p civ6-data-rs --test pool
```

Rustは形・人数・分類と地域の配分・IDと名前の重複・読み・特性・出典の記録と日付・架空所属を検査する。既存22当主の対応は実際のSQLと照合する。出典の文章が史実として正しいかは、この形の検査だけでは保証せず資料と照合する。

## ゲームへの接続

台帳からゲームと開始設定の登録データをRustで生成する。選択済みの人物はCiv6の本体の重複禁止に従い、同じ文明の別人物は選べる。人間の席を席番号で推測せず、各プレイヤーの状態で判定する。2人のホットシートとLANで同じ絞り込みを使い、固定日本のシングルプレイは既存22当主を維持する。

個別肖像と三言語の人物説明の完成は別工程とする。表示名・分類・特性の欠落を防ぎ、個別画像がない人物には他人の肖像を付けない。ゲームでの選択・開始・人物IDと特性の保存・再読込は実機で検証する。
