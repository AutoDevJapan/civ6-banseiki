# Civ6用万世紀

万世紀は、戦国時代の日本列島で武将を育て、日本統一を目指す『Sid Meier's Civilization VI』向けの MOD です。開発中の公開ソースには、保存と再開などの検証用の試作が入っています。

**[公式 Wiki](https://github.com/AutoDevJapan/civ6-banseiki/wiki)** に、試作の使い方、開発ガイド、利用条件をまとめています。

## 作業を始める前に

[リポジトリルール](documents/repository-rules.md)と[開発資料の索引](documents/README.md)を確認してください。変更は作業ブランチからプルリクエストを作って提出します。
