# Civ6用万世紀

万世紀は、戦国時代の日本列島で武将を育て、周回を重ねながら日本統一を目指す『Sid Meier's Civilization VI』向けの MOD です。開発中の公開ソースには、保存と再開などの検証用の試作が入っています。

**[公式 Wiki](https://github.com/AutoDevJapan/civ6-banseiki/wiki)** に、[保存と再開の試作を試す手順](https://github.com/AutoDevJapan/civ6-banseiki/wiki/%E8%A9%A6%E4%BD%9C%E3%81%A7%E4%BF%9D%E5%AD%98%E3%81%A8%E5%86%8D%E9%96%8B%E3%82%92%E8%A9%A6%E3%81%99)、開発ガイド、利用条件をまとめています。

## 作業を始める前に

必ず [リポジトリルール](documents/repository-rules.md) を読んで従ってください。[開発資料の索引](documents/README.md) から仕様を調べられます。変更は作業ブランチからプルリクエストを作って提出します。
